# Nonpatient sparse-cube nonuniform readout

`scripts/mechanics_nonpatient_sparse_nonuniform_readout.py` is a source-only audit of the four frozen nonuniform cube cases (`n5`, `n9`, `n13`, and `n13` half-step). It reads complete saved FEBio node, element, and solver text through `check_nonuniform_readout`; the lower-level parsed-record entry point requires its caller to run the existing strict saved-output and solver-residual checks separately. Neither entry point runs FEBio or establishes source, deck, runtime, backend, or output-file provenance. A supervised native release must bind those independently. This numerical cube has no patient anatomy, measured brain material properties, or surgical interaction observations.

At each saved state, the readout reconstructs `F=(Σ xₐ⊗∂Nₐ/∂ξ)(Σ Xₐ⊗∂Nₐ/∂ξ)⁻¹` at the eight pinned `TET10G8` points. It requires positive reference and deformation Jacobians and uses the frozen `μ=1000 Pa`, `K=9666.666… Pa` alpha-2 Ogden gauge: `W=μ/2(J⁻²ᐟ³ tr(FFᵀ)−3)+K/4(J²−1−2 ln J)`, `σ=μJ⁻⁵ᐟ³(FFᵀ−tr(FFᵀ)I/3)+(K/2)(J−1/J)I`, and `P=JσF⁻ᵀ`. It compares **every** saved element `sx,sy,sz,sxy,syz,sxz,J,sed` column with the reconstructed *arithmetic* eight-point mean. FEBio’s element data writer uses arithmetic Gauss means. Physical total energy is reported independently as `Σₑ,q Wₑq det(dX/dξ)ₑq wq`; the eight quadrature weights sum to `1/6`. Saved `sed × element volume` is **not** treated as physical energy for a nonuniform field, and terminal boundary work is not equated to energy.

The logged stress limit is the unchanged declared `0.01 Pa`, the logged `J` limit the unchanged `1e-6`, and the logged density limit is the existing `1e-8 J` affine energy allowance divided by the declared `1e-6 m³` cube volume (`0.01 Pa`). These are software consistency tolerances, not measurement error bounds. Independently, the readout assembles `f_int,a=Σₑ∋a,q P∇XNₐ det(dX/dξ)wq` in newtons. Each free node must satisfy `‖f_int‖≤1e-8 N` and have `‖R‖≤1e-8 N`; each constrained top/bottom node must satisfy `‖f_int+R‖≤1e-8 N`. This **prospective, per-node** gate is stricter than the parent declaration’s global `1e-5 N` force-balance gate. FEBio’s `R` is body-on-constraint, so its sign is negative the applied load needed to hold the node. A saved, committed native tet10 affine control verifies this sign and integration to below `1e-9 N`; an additional local check against the private n5 affine native cube gave about `1.3e-13 N` maximum top/bottom residual before this nonuniform readout was frozen. Those controls do not predict a nonuniform result. The existing global force and current-moment checks remain required through the text entry point.

The same seven **physical** sample points from the unchanged declaration are located in the straight reference tet10 mesh. The center has six containing tetrahedra and each other point has two at all three mesh levels. The readout checks the expected multiplicities, shared simplex ownership, reference-coordinate reconstruction within `1e-12 m`, and all containing displacement interpolants’ agreement within `1e-12 m`; it reports the lowest element-ID value after agreement and the maximum disagreement. It does not assign a unique stress or deformation gradient at an interface point. The seven-by-three displacement array and the separate signed top and bottom reaction vectors are ready for the existing cross-mesh/half-step convergence checker. No convergence claim follows from this readout alone.

Generated controls exercise all seven interface points on n5/n9/n13 for affine and quadratic fields, the weighted energy identity for a quadratic nonuniform field, million-Pascal stress/density corruption, locally wrong but globally balanced reactions, exact sign against a retained native tiny affine record, and malformed or unaligned records. A generated quadratic field that obeys the prescribed top/bottom motion still fails free-node equilibrium; this negative result is expected because it is not a solved state. A separate one-use release, actual n5 nonuniform output, and independent audit are required before treating any nonuniform case as a numerical software pass. Mesh/time-step convergence and independent physical displacement/force validation remain later gates.
