# Bounded surgical RL pilot

`scripts/train_surgical_pilot.py` prepares one small optimizer-updating experiment on the existing sub-06 and UCSF-PDGM-0004 development anatomies. The acquired images and supplied/estimated segmentations retain their original roles and affine geometry. Experience is generated by the surgical engine. It is not recorded surgical experience, held-out evidence, clinical validation, or an end-to-end surgical policy.

The runner has two stages. `prepare` executes real exposure prefixes, verifies a local target-removing CUSA option, checks whether a fixed Frazier suction continuation works, and compares cached episode forks with complete public-action replay. It writes zero optimizer updates. `train` additionally requires a separate launch receipt issued by the lead after both cases have been demonstrated in the desktop and the shared guards, performance and telemetry have been checked. Source/code hashes and settings must still match preparation.

```sh
PYTHONPATH=src .venv/bin/python scripts/train_surgical_pilot.py --mode prepare
PYTHONPATH=src .venv/bin/python -m pytest tests/test_surgical_pilot.py
# Only after the lead has supplied the prerequisite receipt:
PYTHONPATH=src .venv/bin/python scripts/train_surgical_pilot.py \
  --mode train --launch-gate outputs/surgical-pilot-v1/launch-gate.json
```

The fixed experiment uses three seeds (17, 29, 43), four Adam updates per seed, two episodes per update (one per anatomy), and at most six CUSA decisions per episode. A small shared 20→32→1 candidate-scoring network is trained by on-policy REINFORCE, discount 0.95, learning rate 0.001, entropy weight 0.01, fixed return scale 100 and gradient norm limit 1. A 900-second wall budget, 1,000 public-transition-call budget, 10-second action-latency budget and 6 GiB peak process RSS cap stop the run on a measured blocker. These are development software budgets, not operative or clinical thresholds. There is no parameter sweep or best-seed selection. The runner refuses implicit repeat fitting in an output directory that already records optimizer updates.

Every method receives identical local observation features and nine candidate commands: two-millimeter CUSA movement in each of the six world-axis directions, stationary application, inspection and an explicit STOP. STOP executes a real engine deactivation, incurs its measured reward/cost, and ends this local task by policy decision. It does not fabricate whole-environment target success; the underlying replayable engine remains at the resulting state. A six-decision cap is separately labeled local truncation. Features summarize the environment's local sampled material, target, protection, fluid, bone-temperature, displacement, cut and known-grid channels. The policy and candidate provider accept observations only. They never receive engine state, source maps, preview outcomes or `info`. Global target centroid and aggregate reward metrics are deliberately unused by action selection. The local observation spacing is explicitly 1 mm for this task; it does not change source geometry.

Assessment includes the same initialized untrained policy, a seeded uniform random policy, a fixed inferior-advance script and an observation-only local greedy geometric policy. The latter adapts the existing native observed-greedy principle of nominal target gain minus burden. The greedy adapter explicitly chooses STOP when none of its observed nominal gain-minus-burden scores exceeds the stop cost. This is a declared local threshold heuristic. The native `NativeSpatialTask` search implementation is incompatible with `SurgicalRLEnv`; this is explicitly a local adapter, with no claim of existing-search equivalence or global optimality. The learned and untrained assessments use deterministic argmax; training samples actions. Both anatomies participate in optimization and assessment, so results can describe only this development pilot.

Exposure is an explicitly engineered task setup. Sub-06 uses the existing checked eleven-stroke drilling approach before CUSA enters the target. UCSF uses its existing target, vessel and protection maps to choose a superior column with no declared dilated obstruction and minimum modeled healthy overburden. That privileged geometry is used to freeze a common exposure prefix, never to choose policy actions. All tissue changes occur through checked engine transitions; there is no crop, relabeling, pre-removal or direct pose injection. The exploratory highest-target UCSF route was blocked at a vessel after 33 mm³ healthy removal and zero target removal; its original preflight snapshot remains under `outputs/surgical-pilot-preflight`. The subsequently frozen minimum-overburden route reached target with 16 mm³ healthy removal and 8 mm³ target removal in the initial preflight. These quantities must be regenerated when the shared engine changes.

The fixed full-episode setup healthy-removal cap is 100 mm³. A further 5 mm³ incremental healthy-removal threshold is checked after each real action and stops the local task when exceeded. It can overshoot within the last action; that is a budget failure, not a guarantee that every admitted action remains below 5 mm³. Protection, vessel and bleeding limits remain enforced by the environment. Setup burden stays in cumulative metrics and reward, and local metrics show changes after exposure separately. Consequently a favorable local score cannot erase setup injury. The task is not whole-tumor completion. Prefix execution is amortized once per anatomy, copied using the engine's native rollback clone, and its real time and transition count remain in the cost report. Final trained replay files include the entire prefix and all later public actions.

If preparation verifies four accepted commands and actual debris removal, every assessment arm receives the same fixed withdraw/exchange/reinsert/apply Frazier suction tail after CUSA. The tail does not belong to the learned action set and is explicitly reported separately; it cannot support a claim of learned instrument switching. If that continuation is unsupported on an anatomy, it is omitted and the failed preparation evidence is retained.

Outputs include a hash-bound preparation receipt, the cumulative cost of recorded preparation attempts and this fit/assessment/replay run, each baseline and training trajectory, decomposed rewards, actual gradient norms and before/after parameter hashes, all three checkpoints, and complete final replay snapshots. Earlier manual exploration is reported separately and is not silently included in those measured runner totals. The summary retains every seed and paired trained-minus-baseline differences. A failed run retains its partial records and reports `blocked`; missing final results are never filled with inferred wins. The old restricted learning entrypoints and their historical checkpoints remain untouched; this script's separate admission is limited to the explicitly requested two-source pilot.

The admitted run completed on 2026-10-18 after the lead verified the actual Electron two-case demonstration, native save/reopen, shared guards, performance and independent telemetry. The [versioned result and complete comparison](../artifacts/surgical-pilot-v1/RESULT.md) retains all seeds, source/parameter hashes, checkpoints and full replay evidence. All 12 Adam updates changed parameters; all six final trajectories replayed exactly. The trained assessments removed zero additional target on both anatomies, and no checkpoint is promoted. Sub06 mean local return was -0.0032 versus the budget-eligible fixed script's +0.1008 (108 mm³ additional target, zero healthy). UCSF trained mean return was -0.2048 versus eligible random's -0.140267 (mean 4 mm³ target and 3 mm³ healthy). The UCSF script removed 14 mm³ target but crossed the local healthy threshold at 6 mm³ in every seed, so it failed the declared budget and is excluded from eligible-baseline ranking. Vessel, bleeding and protected damage stayed zero in all assessed arms.

Across six trained assessments, the policy issued three STOPs, zero inspections and six shaft-collision rejections in 21 commands. Its other twelve commands were accepted alternating z moves with zero target gain. Training sampled 119 commands and included target-removing transitions, but deterministic final assessment did not retain that progress. Combined losses and pre-clipping gradient norms are finite and recorded in the [12-update CSV](../artifacts/surgical-pilot-v1/update-curve.csv); these values and parameter changes establish actual optimization, not useful learned surgical behavior. Both fixed Frazier probes removed zero debris, so no suction tail or instrument-switching claim is included.

The fit/assessment/replay run cost 350 transitions and 190.888 seconds, with 2.019-second maximum action latency and 736,559,104-byte peak process RSS. Including four preparation attempts (one blocked when a source file changed), the recorded total is 550 transitions and 413.638 seconds. The [read-only post-hoc audit](../artifacts/surgical-pilot-v1/verification.json), [all 30 assessment rows](../artifacts/surgical-pilot-v1/all-seed-assessment.csv) and [complete reward trajectories](../artifacts/surgical-pilot-v1/result.json) preserve the negative result and budget failure. No further fit or parameter sweep was performed.
