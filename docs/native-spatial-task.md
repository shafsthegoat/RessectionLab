# Native spatial task boundary

`native_spatial_task_from_case(case, *, access, tools, max_steps=3, track="annotation_assisted", nominal_target=None, nominal_target_derivation="", crop_shape=(32,32,32), cancelled=None)` composes the existing native complete-tool engine with the frozen six-channel observation interface. Access is canonical RAS+; source LPS+ arrays retain their samples and receive a physical-frame conversion. No patient execution or learning result is established by this module's analytic tests.

The real-case factory requires working brain support accepted by the existing source-bound review/assumption contract. Absent support, full-head nonzero signal and view-only extraction proposals never become working tissue automatically. A support research assumption alone is not evidence of a scan-derived model. Annotation-assisted mode supplies active preoperative target compartments explicitly. Inference-only mode never substitutes those references for an absent prediction; SEARCH refuses a missing nominal target. There is no MRI target intensity threshold. Supplied predictions require a recorded derivation; the caller retains checkpoint/source artifacts alongside the case receipt.

The optional `research_support_acknowledgment` enables one separately declared provisional model envelope for **annotation-assisted research only**. It binds schema/purpose, source case and planning identities, proposal/image/frame/mask/model/run hashes, declarer, aware timestamp and rationale. Explicit unreviewed acknowledgment is required; clinical-use and cortical-access permissions remain false. Rejected or already reviewed proposals cannot use this provisional path. The source case, `brain_mask`, proposal review and general planning gates are unchanged. Both policy and SEARCH use the exact declared mask. The full declaration remains in task metrics and source/model identities. PAT05's main proposal is the prospective first input because its supplied annotation has zero cells outside the estimated envelope; PAT16/PAT20 main and all inspected no-CSF variants have conflicts. This input-completeness rule is not a segmentation-accuracy finding or route-reward selection.

`intensity_normalization="support_percentile_1_99"` explicitly opts into linear 1st/99th-percentile bounds from the entire permitted envelope. Those finite bounds, source/support identities and the `[0,1]` clipping rule are frozen and reported; equal bounds are refused. Only the actor crop is transformed. The raw MRI, native physical geometry and supplied annotation remain intact. Targets, hidden references, outcomes and actor crop do not select normalization statistics. Default `"raw"` preserves earlier behavior. Access may itself be declared using supplied annotations in this track; that does not establish inference-only localization.

`native_grid_reconciliation="orthogonal_roundoff_1e-6mm"` is a separate explicit option for source-header roundoff. It projects normalized source axes to an orthogonal basis while preserving their original lengths, handedness and origin. It refuses normalized Gram error above1e-8 or displacement above1e-6mm at any of the eight full source-cell extent corners `[-0.5, shape−0.5]`. Original and derived matrices, shape, hashes, bounds and observed displacement remain in metrics/source identity; the original `affine_ras_mm` and all image/mask samples remain intact. Crop and proposal **indices** use the original source affine; physical tool endpoints, native geometry, actor crop frame and independent history checker use the same declared derived affine. No engine tolerance, access, tool, reward or sampling grid size is changed. The default is `"none"`.

The [first real PAT05 profile](../artifacts/pat05-real-spatial-profile-v1/outcome.json) failed the unchanged engine's orthogonality guard before previews, policy forwards or updates. Its source-axis Gram error was 6.788716e-10; the explicitly proposed reconciliation moves full-cell corners by at most 1.0842083e-7 mm. The [independent header diagnosis](../artifacts/pat05-affine-header-diagnosis-v1/diagnosis.json) confirms the bundle exactly preserves the selected float32-stored sform. Its tiny nonorthogonality is consistent with serialization roundoff; the unavailable pre-serialization matrix prevents proving the cause. Replacing it with qform would change source-axis lengths and move corners by 1.254071e-5 mm, exceeding the declared bound. That shortcut is excluded. The failed run remains a negative result; this engineering reconciliation does not fix source-cell discretization dependence or establish anatomical validity.

Full source-grid geometry, containment, connected frontier, prior-cavity shaft clearance, and complete-tool access checks remain authoritative. The actor sees a fixed crop chosen only from scan shape/affine and the declared access, with original voxel spacing. Default dimensions are at most32³, configurable through64³. Crop coordinates remain float64 until policy sampling. The native engine is not cropped or resampled. The partial view is not claimed to be a complete Markov description of a whole patient.

Small analytic sources enumerate every support-cell/tool pair. Larger sources use a declared three-column/eight-depth source-grid lattice around access, clipped to the actor crop. Every lattice slot is checked; reasons and all counts are retained. This is complete within the declared local primitive family, not coverage of all surgical paths. Neither reference labels nor target predictions choose or order candidate endpoints. Each accepted row preserves its actual entry, tip and full tool configuration. Native target labels are zero; a separate evaluator scores committed source cells. `planning_clone()` substitutes only the permitted nominal target, re-scores past records, and shares immutable source/certificates while copying mutable engine state; it does not replay geometry.

That fixed lattice remains the default. The separate `proposal_mode="nominal_cavity_v1"` opt-in uses `PreparedNominalCavityProposer` with an explicit hashed **permitted** nominal target and provenance outside the engine; engine target labels must remain zero. Its default is the previously declared 13 source-column offsets. Each column/tool has three dispositions: nearest exposed remaining-tissue opening, proximal remaining nominal target and distal remaining nominal target. Openings use observed remaining tissue with a face adjacent to connected free space; nominal endpoints use the supplied annotation/estimate and current cavity. No private reference, reward consequence or learned value selects these endpoints. Every distinct emitted tool/entry/tip receives a complete native preview; only accepted certificates become policy/SEARCH actions. Exact geometry duplicates and the fixed maximum96-candidate cap are reported separately, with a complete disposition ledger. STOP remains available. This changes the action model explicitly and leaves the earlier axis proposer and fixed-lattice workflows intact.

The nominal/cavity extent is **not clipped to the actor crop**. Source indices are chosen in the original frame; endpoints use the declared native physical frame and are projected onto the unchanged aperture for their actual entries. The crop can therefore omit target evidence along a proposed ray. `candidate_inventory()` exposes unique `emitted` rows, including geometry rejections, their coordinates, endpoint visibility, source/provider/evidence/cavity identities, family/cap/duplicate/unavailable counts and terminal/horizon state. Continuous ray coverage is a separate diagnostic, not a clearance claim. The same immutable provider serves the actual task and `planning_clone()`; only permitted nominal scoring replaces private evaluator outcomes. Teacher diagnostics must retain completed search layers, negative prefixes and STOP comparisons; an incomplete search is not an optimum, and an untrained behavior-cloning critic is not a search value oracle.

The analytic opening control uses an explicitly different 3×3 column test configuration to expose its diagonal obstacle; production retains the 13 declared offsets. Its initially blocked distal nominal stroke becomes legal after a paid opening with another tool, and the resulting history passes the independent native check. Hidden reference swaps preserve observations, proposals/masks and teacher state before and after that cut. Other controls cover candidate caps, duplicate rays, stale ledgers, frame reconciliation and rejected endpoints beyond the actor crop. These checks involve no synthetic training or patient rerun. Initial owner runs passed nine new controls and 63 existing controls; after adding a stale-batch check and runtime identity fields, the combined 73 checks passed in 5.42 seconds. Independent review follows this owner evidence.

The geometric objective retains target/non-target volume, action, complete insertion-plus-withdrawal distance and tool-change costs. Partial-contact, motor/language and graph costs are disabled explicitly. Contact counts remain separate from removal; functional and vascular coverage are unassessed and clinical probabilities null. This adapter does not yet implement probabilistic functional planning; that work remains in the evidence-aware planner. `reset(seed=0)` supports one deterministic geometry world and rejects other scenario seeds. A post-commit cancellation retains the executed transition via the existing committed-transition exception.

The nine-by-nine-by-seven **code fixture** contains six tissue cells, two distal targets and a diagonal shaft obstacle. A short wide opener clears the obstacle; the unchanged longer narrow cutter then reaches the targets. Exact finite enumeration checks the two-step sequence and independent full-history geometry. An earlier lateral-obstacle layout failed the intended capability test: the cutter could remove that obstacle through its own entry. That negative prompted the diagonal/aperture fixture; no tool dimensions or clinical data were changed. These are analytic regression checks, never synthetic training, a generalization benchmark, or evidence of clinical usefulness.

The separate [fixed physical scene discretization control](../artifacts/native-discretization-control-v1/RESULT.md) found substantial source-grid dependence: the same physical tool/path accepted on aligned 1mm cells but failed shaft clearance on shifted/rotated grids; finer 0.25mm variants passed. Fully contained-cell credits still underestimated ideal continuous sweep volume on the finer checks. Independent geometric acceptance therefore establishes this declared source-cell model's internal checks, not resolution-independent removal accuracy. No interpolation, enlarged tool or partial-cell removal is substituted to hide this limitation.

The [PAT05 input declaration](../artifacts/native-spatial-PAT05-input-v1/input-binding.json) records the exact provisional main envelope and one annotation-assisted nearest-axis boundary access, selected without a reward or feasibility sweep. Its fixed32³ scan/access crop includes2,786 of11,437 supplied annotation cells (24.36%) and18 source-grid primitive endpoints, giving36 slots for two tools. The annotation representative lies beyond that local crop. This is a bounded integration preflight, not coverage of the complete tumor or evidence of patient benefit; the input record contains no executed native preview or learning result.
