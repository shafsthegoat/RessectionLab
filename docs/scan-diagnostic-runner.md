# Case4 diagnostic handoff

`resectionlab.scan_diagnostic_runner` is an opt-in file handoff for one RESECT Case4 DEVELOPMENT diagnostic. It verifies the exact saved scan-only preparation and support-map receipts. `write_case4_model_input(root, destination)` also rehashes the bound inputs and model metadata before preparing one `[1, 2, 128, 128, 128]` patch. The input receipt binds the complete inverse geometry, physical frame, source hashes and patch bytes. Its generated-control counterpart has an unverified schema that the patient worker rejects.

The model launch is **disabled** in this source version: `CASE4_FORWARD_RELEASE_SHA256` is `None`, and no patient `pair-contract.json` is supplied. The accepted generated full128 recompute result establishes resource/finite-output feasibility only. A later Case4 one-shot release must pin the exact patient input receipt, adapted worker/supervisor source, checkpoint, process allowlist and unchanged resource limits, then receive independent prospective review. The actual output must pass independent post-run receipt checks before `write_case4_display_from_saved` can decode it. Run patient preparation and decoding under a reviewed bounded supervisor, not from a desktop render callback.

The display descriptor and separate NIfTI state/coverage volumes are for a local viewer layer on the exact source grid. `-1` means unknown; `0` and `1` are candidate output states only where both the limited scan-derived domain and verified output coverage are present. The layer cannot become a `CaseData` compartment, route constraint, evaluation label or clinical evidence. The source T1c role is inferred from cohort protocol without per-file contrast proof; registration and mask anatomy remain unreviewed, the inferior/cerebellar mask omission remains visible, and model training overlap is unknown. Desktop integration is a separate task.

Generated controls in the pinned optional runtime: `.tools/scan-target-runtime/venv/bin/python -B -m unittest -q tests/test_scan_diagnostic_runner.py`. A base environment without pinned metadata/runtime skips at collection; malformed present metadata still reaches the fixed hash check in the pinned runtime. No test opens patient pixel arrays, checkpoint weights or a trained network.
