# Clinical inputs and the testable value of RL

Primary sources checked October 4, 2026. This describes input contracts and
research hypotheses, not clinical readiness. It extends
[the surgical-realism evidence](rl-surgical-realism-evidence.md).

**What Medivis actually documents.** Studio accepts CT/MRI studies, supports
manual/semi-automatic segmentation, derived 3D models, measurements and
annotations. Its documentation does not establish that a surgeon receives a
complete vessel, tract or functional map automatically.
[Official Studio description](https://www.medivis.com/studio/personal).
The Spanish product page advertises STL import/export, but this is not a verified
RessectionLab interface: units, coordinates, source-image identity, labels and
review status still require an explicit handoff contract.
[Official export claim](https://www.medivis.com/es).

Product boundaries matter: the October 2025 FDA summary for **NeuroAlign**
describes pre-acquired PACS/local data, tracked tools and patient registration;
it specifically excludes integration with intraoperative microscopes/ultrasound
for that device. Broader website platform features cannot establish a supported
live-data API or autonomous glioma planner.
[K231897 device description](https://www.accessdata.fda.gov/cdrh_docs/pdf23/K231897.pdf).

**What to request from the surgeon/hospital.** Original images and acquisition
metadata are the foundation; derived labels should retain the source study,
physical frame, timestamp, author/method and review status. The following is an
engineering intake contract, not an instruction to acquire every listed scan.

| Input | Practical use and boundary |
|---|---|
| Structural MRI: T1 before/after contrast, T2 and FLAIR | Clinical anatomical baseline; identifies different visible tumor/abnormality compartments. Request the actual sequences available. A single research volume is not a complete clinical protocol. |
| Target and intracranial/support annotations | Distinguish enhancing tumor, nonenhancing abnormality, necrosis and edema according to the source labels. Masks are estimates, not histology; skull stripping does not identify a reviewed cortical entry. |
| CT, when available and relevant | Supplies complementary anatomy; ordinary CT does not substitute for the MRI/functional evidence above. Do not make CT a universal prerequisite for a glioma research case. |
| Vascular evidence | Request acquired CTA/MRA and relevant venous imaging, plus separately reviewed artery/vein segmentations and registration. Structural MRI may show vessels, but no vessel label is not evidence of a vessel-free route. |
| Diffusion and functional evidence | Retain raw diffusion data, gradient tables, acquisition/correction metadata and tractography settings; task fMRI needs its task and quality record. Preserve stimulation/monitoring findings as distinct observations. |
| Surgical context | Clinician-declared access region, intended target, protected anatomy, tool identity/full geometry and motion limits, patient positioning, prior treatment and availability timestamps. Do not infer acceptable tissue damage from tool dimensions. |

EANO supports the structural MRI baseline. A recent primary glioma study compared
T2 vessel visualization with CTA/TOF-MRA, illustrating complementary acquisition
and processing rather than a universal vessel map.
[EANO](https://pmc.ncbi.nlm.nih.gov/articles/PMC7904519/),
[vascular visualization study, 2026](https://doi.org/10.1016/j.jocn.2026.112174).
Prospective language-mapping validation found modality/reference-dependent
performance; fMRI, tracts and stimulation are not interchangeable.
[Primary mapping study](https://pmc.ncbi.nlm.nih.gov/articles/PMC10248363/).

**Minimum usable research mode:** a spatially valid structural volume, a target
annotation, declared support/access/tool assumptions, and explicit missing-data
coverage can support geometric comparison and simulation. Estimated support
remains labeled estimated. Vessel or functional scoring requires the respective
evidence and acceptance gates; missing inputs remain unassessed. Neither RL nor
search can identify all unseen perforators, essential language sites,
microscopic invasion, material properties or injury tolerance from that volume.
Additional imaging and clinical observations enrich the state; they are not
facts generated by choosing a stronger optimizer. Intraoperative observations
also need versioned updates because measured brain shift changes geometry.
[Serial intraoperative MRI evidence](https://pubmed.ncbi.nlm.nih.gov/11322439/).

**Why consider RL when search already works?** For a small deterministic route
list, evaluate the routes directly. RL's possible benefits are amortizing repeated
decisions, learning long-horizon choices as actions change future access, and
using informative observation histories. These remain hypotheses here. Learning
and search can cooperate: policy-guided heuristic search learns which branches
to expand; TD-MPC2 combines learned models/values with trajectory optimization.
Neither result proves a surgical benefit.
[Policy-guided search](https://ojs.aaai.org/index.php/AAAI/article/view/17469),
[TD-MPC2, ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/hash/cf73d57b6dcda32b293df7c2d5341f49-Abstract-Conference.html).

**Three measurable tests, proposed rather than completed:**

1. **Amortization:** compare exhaustive/beam search, scratch RL, frozen/adapted
   policies and policy-guided search on identical held-out queries. Report
   removal/contact tradeoffs, invalid-action rate, wall time, peak memory and
   simulator calls. Include training/adaptation cost; measure the query count at
   which total learned-method time becomes lower at matched quality. If there
   is no crossover, report no amortization benefit.
2. **Sequential decisions:** construct frozen multi-action cases where cavity
   changes affect later feasibility. Match observations, tools, action inventory
   and computational budgets. Compare RL with greedy and deeper search; use
   exhaustive solutions for small horizons to measure regret. Sweep horizon and
   branching, recording target removal, non-target contact and constraint
   violations independently of scalar return.
3. **Partial observability:** supply timestamped noisy observations of a declared
   hidden simulation variable. Compare recurrent RL, history-blind RL and a
   search baseline using the same observation history/belief update. Measure
   held-out regret, constraint violations and observation cost, with an
   uninformative-observation control. Memory should help only when the history
   carries usable information; it must not expose hidden anatomy to one method.
   [Recurrent POMDP baseline study, ICML 2022](https://proceedings.mlr.press/v162/ni22a.html).

All tests retain the existing optimization/selection/evaluation split and frozen
reward/world contracts. Any gain is a simulator result, not clinical injury
prediction or proof that more tissue should be removed.
