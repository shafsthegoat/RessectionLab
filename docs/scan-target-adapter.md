# Scan-only adapter source slice

This integrated optional research module depends on the isolated, pinned `.tools/scan-target-runtime/requirements-lock.txt` environment (nnU-Net 2.5.2, ANTsPyx 0.6.1, SimpleITK, nibabel and Torch). Keep its import out of the base desktop app's startup path. Generated validation: `ITK_GLOBAL_DEFAULT_NUMBER_OF_THREADS=1 .tools/scan-target-runtime/venv/bin/python -B -m unittest -v tests/test_scan_target_adapter.py`. This suite uses generated images, a dummy network constructor, and no patient/model forward.

The exposed diagnostic wrapper reads exact-hash Case4 preoperative T1c/FLAIR and the pinned SRI24 atlas, verifies the existing exact-input SynthStrip T1-mask record, computes scan-only rigid FLAIR→T1c and T1c→atlas transforms, and writes transform receipts plus ordered atlas-space nnU-Net channels. The mask has known limitations, so the result remains **diagnostic-only and anatomically unreviewed**. The generated tests verify physical frames, channel order, transform direction, inverse nearest-neighbor labels, coverage and typed abstentions. They do not validate Case4 registration quality, skull-strip adequacy, tumor segmentation, whole-volume prediction or surgical routes.

The small Case4 manifest pins original scan/atlas/mask/SynthStrip-record bytes and the model extraction receipt. Its two metadata receipts are exact-byte tracked copies; all admission flags remain false. The model's training lineage and Case4 overlap remain unknown. The next concrete step, under a separate bounded DEVELOPMENT release, is a scan-only preprocessing attempt that generates Case4 registration outputs and receipts. Review the resulting local correspondence, mask/ROI omissions, coverage and inverse native mapping **after** that attempt and **before** any diagnostic model inference or planning. A later bounded research-planning experiment may use a scan-derived WT estimate only after exact native-frame support mapping and ROI/coverage checks; no direct clinical or production planner admission follows from this source slice.

The base test environment skips this optional module when its imaging/model packages are absent; the nine controls must run in the pinned runtime above. No optional imaging package is imported by desktop startup.
