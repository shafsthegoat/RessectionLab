# Shared surgical protection

`SurgicalEngine` now owns the critical-structure exclusion checks used by desktop and RL actions. The RL subclass only adds reward ledgers. Supplied masks remain explicit, source-bound research evidence; their names do not create anatomy or establish anatomical completeness.

```python
from resectionlab.surgical_engine import SurgicalEngine
from resectionlab.surgical_rl_protection import GuardConfig, load_protection

protection = load_protection(scene, "rl-protection.json")
engine = SurgicalEngine(scene, protection=protection, guard_config=GuardConfig(
    require_critical_coverage=True, critical_max_displacement_mm=0.))
```

Both slots' swept working geometry and shafts are checked before each physical microstep, including parked inactive instruments. Before a microstep commits, the shared engine also checks protected source-cell removal, cut endpoints, continuous displacement, displacement of an indirectly grasped fragment, generic thermal exposure, drill temperature/dose increases, and V2 vessel injury. A displaced protected raster is checked against the instruments again. A rejected microstep restores its prior physical state; earlier admissible microsteps remain a deterministic partial action. RL strain/proximity ledgers update only after the common checks pass.

The default displacement allowance is zero. A nonzero allowance follows the same lattice occupancy used for collision and rendering; it does not certify a displacement as safe. Registered masks may overlap a tumor label, and the protected source membership still wins for exclusion and reward eligibility.

## Persistence and explicit missing evidence

`snapshot().protectionContract` contains the exact annotation cells, source binding, provenance, review status, required identities, clearance, and `GuardConfig`. A content digest binds that contract into the engine state identity. `SurgicalEngine.restore(scene, record)` reconstructs and verifies it before replay; changing or omitting it cannot silently reproduce the saved guarded identity. The contract travels inside the native archive, so it does not depend on an external JSON/NPZ file remaining available.

`fresh()`, `reset()`, `branch()`, and `replay()` preserve the contract. Desktop reset now uses `fresh()`. `SurgicalRLEnv.from_patient()` reads an embedded native contract automatically and rejects a conflicting supplied protection file or guard configuration. Historical engine snapshots with no contract retain their original replay interpretation and state identities.

`view.protection` and `observe().protection` report:

- `strict-research`: required masks, including brainstem, are present; only declared masks are guarded.
- `relaxed-research`: missing required evidence was explicitly permitted. Any supplied masks remain guarded.
- `unconfigured-research`: a historical/bare engine was constructed without protection configuration. Missing critical evidence remains unknown.

Fresh desktop scenes explicitly record relaxed research mode. All modes report unknown anatomical completeness and no clinical validation. This work does not infer functional cortex, tracts, optic pathways, cranial nerves, or other missing structures. Unreviewed imported estimates retain their review status.

The only optimization reuses that exact digest across result/history and preview/view assembly. There is no persistent state-digest cache and no change to collision resolution, physics integration, or microsteps. The measured step includes cloning the fixed starting engine and checking its resulting identity. The sweep query measures full action geometry against protection and excludes indirect postchecks. Reset now verifies and hashes self-contained protection evidence, which adds patient overhead. Five samples describe this fixed workload; they do not establish general interactive latency or training throughput.
