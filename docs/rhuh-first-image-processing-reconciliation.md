# First RHUH image: processing and frame reconciliation

This October 5, 2026 review used saved inspection JSON and primary preprocessing documentation/code only. No image was reopened, decoded, segmented or imported; no outcome records were consulted. The inspected source remains RHUH-0001, visit 0, source-labeled T1.

The [published paper, §3.1](https://pmc.ncbi.nlm.nih.gov/articles/PMC10551826/) describes T1ce registration to SRI24, registration of other modalities to that transformed T1ce, 1 mm isotropic resampling, SynthStrip brain extraction, and structural intensity Z-scoring with CaPTk 1.9.0. This establishes a **cohort-level processed-image description**, not an authenticated processing history for this exact file. The saved 240 × 240 × 155 grid at 1 mm is compatible with processed data; shape alone does not identify the atlas/template version.

The saved qform is finite and invertible, with code 1 and L/P/S voxel-axis directions; sform is absent. Code 1 does not override the processing description or prove scanner-native coordinates. Exact-file registration transforms, template identity, processing version and anatomical alignment remain unverified. No absent transform should be reconstructed from dimensions or assumed voxel correspondence.

The [pinned author shell](https://github.com/smcch/RHUH-GBM-dataset-MRI-preprocessing/blob/46cf3825278243036c08131b62dcfcfb1d3bba39/final_pipeline.sh) uses 12-parameter affine registration, trilinear interpolation and a mask supplied to CaPTk normalization (`-zn 1 -zq 5,95 -zc 3,3`). Its environment path names **1.8.1**, differing from the paper's **1.9.0**. The [later Python alternative](https://github.com/smcch/RHUH-GBM-dataset-MRI-preprocessing/blob/46cf3825278243036c08131b62dcfcfb1d3bba39/preprocess_mri.py) instead subtracts the whole-array mean and divides by its standard deviation. Neither code listing proves which implementation produced the released file.

The saved intensity mean is −7.312971, with range −8.976039 to 10.492467. That mean is inconsistent with assuming unchanged output from the later whole-array zero-mean normalization. Mask-based normalization leaving negative background is plausible, **not established**. These statistics cannot identify background, intracranial support, tissue or physical intensity units. Nonzero intensity must not become a brain mask.

Prospective display-only QC, requiring separate release: show full-field native index planes **120/120/77**, fixed by `floor(shape/2)`, with qform-derived direction labels and 1 mm aspect. Use identical planes with two predetermined windows: the saved full range and **−3 to 3**. Preserve original pixels/affine; no resampling, overlays, support derivation or scientific normalization. Record coverage, gross artifacts and uncertain brain extraction only on sampled planes; this is not whole-volume anatomical acceptance. No such display has run.
