# HBE v5 first-canary source preparation

This bounded proposal covers only `compression:N8:S60:reference`. The pure v5 adapter starts from the hash-bound, old-endpoint N8 Skyline deck and prepares a fresh 60-step compression deck ending at the exposed coordinate `-0.00073726 m`. It uses the full N8 hex8 specimen (1,045 nodes, 768 elements), the same bonded physical plates, zero lateral plate motion, and a unit top-z factor. It does not reuse old solved states. The other eleven declared v5 rows are untouched.

`manifests/experiments/hbe-v5-n8-canary-source-only-v1.json` freezes the source deck and mesh bindings, verified fixture topology and 630 displacement BCs, exact 61-point time/load schedule, pure adapter receipt, Skyline deck SHA256 `6b43b2a7b5acc46862c576416368a41d926e2214f738036f20491dc81f388cff`, and Accelerate deck SHA256 `3cf4156b19191918841498490bc448f88a61b656b566d5d6a3d36db817d0a724`. The deck bytes live only in ignored `outputs/mechanics/hbe-v5-n8-canary-preparation-v1/`. The existing repaired FEBio 4.13 Accelerate profile and runtime identity remain hash-bound prerequisites; the verifier replays their earlier independent tiny controls without launching FEBio. It opens no measured HBE force/torque CSV and no patient data.

The default `python -B -m scripts.mechanics_hbe_v5_n8_canary` performs read-only verification of the manifest, source, runtime and both materialized deck files. `--materialize-decks` creates only missing ignored deck files from the pure adapter; existing different bytes are refused without overwrite. The module contains no native launch path. `release` remains `null`, and `require_execution_ready()` always fails.

A clean checkout lacks the ignored old deck, mesh, repaired runtime/control files and generated new decks. Verification fails closed until those exact hash-bound local files are supplied; the manifest alone is insufficient.

This source preparation cannot show that the new endpoint converges, that saved solver fields pass the complete v5 stream readout, or that forces agree with specimen measurements. A separately reviewed one-shot supervisor, explicit caps and native execution receipt are still required before a single N8 call. Full twelve-row numerical qualification, calibration and withheld torsion remain later gates. Even those specimen measurements would not validate live patient retraction or neurological injury.
