# HBE v5 source-deck binding gate

This is a non-executable preparation for the one-specimen HBE_01_03 axial study. `manifests/experiments/hbe-01-03-v5-source-deck-bindings-v1.json` binds ten existing old-domain Skyline decks and seven representation-specific mesh JSON files by path and SHA256. Its twelve ordered v5 rows map to those ten decks: compression N36 S120 reuses the compression N36 S60 **source** and tension N24 S120 reuses the tension N24 S60 **source**. A future pure adapter must regenerate the full S120 time/load schedule; an old numerical solution is never reused.

`scripts/mechanics_hbe_v5_source_bindings.py` checks the frozen v5 declaration, the complete mapping and source/mesh hashes. Its pure XML/JSON validator compares every mesh node coordinate and hex8 connectivity, all boundary faces and node sets, singleton top-node sets, and every prescribed displacement. The full model constrains both physical plates in x/y/z; the lower-half model constrains the physical bottom in x/y/z and only z at its artificial midplane, at half of the full-displacement value. There is no side-specific BC; side-rim nodes shared with a plate retain that plate's constraints. The checker fails when a single top-node BC is missing even if the other top-node BCs have the right form.

Local checks found all ten source/mesh pairs consistent: full-domain N8/N12/N16 had 1,045/3,199/7,209 nodes; lower-half N16/N24/N32/N36 had 4,005/12,439/28,233/39,610 nodes. The data live in ignored local `outputs/`; a clean checkout without those bytes can validate only the binding manifest until the exact sources are supplied. The fixture tests use generated eight-node XML/JSON only and never open measured responses, torsion, native logs, or patient files.

This gate establishes file identity and encoded fixture topology. It does not establish numerical convergence, force agreement, physical material validity, patient retraction mechanics, injury, training, or a solver release. `require_execution_ready()` remains unconditionally closed. Later extended-endpoint native primitive checks, twelve-row qualification, independent review, resource-bounded one-shot execution, fitting and withheld torsion remain separate decisions.
