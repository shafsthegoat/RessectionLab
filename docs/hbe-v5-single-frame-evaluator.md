# HBE v5 generated single-frame evaluator

`scripts/mechanics_hbe_v5_frame.py` is a source-only numerical control for one generated HBE axial frame. It has no file reader, process launcher, fit path, or held-out-response access. `verified_schedule` checks the pinned v5 declaration bytes and v4 ancestry hash, regenerates the adapted FEBio deck from the supplied old source, and requires byte-for-byte identity with the supplied actual adapted deck and preparation receipt. It returns the actual signed full and native displacement arrays, including the extended endpoint and the half-height factor. The old source still requires independent identity against the separate v5 source-binding manifest before any future native use; the returned contract explicitly records `source_binding_checked=false` and `native_execution_released=false`.

`evaluate_generated_frame` accepts one pair of records already parsed by `_iter_data_records`, plus an immutable generated mesh manifest. It checks synchronized step and exact nine-digit primitive-header time, current-minus-rest displacement, physical fixture motion, free DOFs, force and moment balance, positive logged element J and sampled deformation J, and finite stress fields. It reuses `HexMesh.deformation` for the pinned three-field hex8 energy and `fixed_probes` for the 75 physical probe locations. For a generated lower-half mesh, it reuses the existing reflection map, sums shared-plane reactions and transforms the logged Cauchy stress tensor; it checks the original force-one and energy-two scales. The raw bottom and top or midplane reactions remain available alongside the canonical signed applied force. The output labels the reflected field `reconstructed_full`, never a native full solve.

The result is a **generated-fixture result only**. Its sign check is an analytical tension/compression control, not a general tissue constitutive rule. Logged stress, J and `sed` are diagnostics; logged `sed` is not used as an energy proof. Positive sampled J is not positivity everywhere. A single frame cannot establish solver convergence, accumulated force–displacement work, actual source-bound topology, numerical mesh/step convergence, measured-force agreement, or physical fidelity. `fixture_passed` must never be interpreted as a native or clinical pass. It cannot authorize HBE execution, fitting, torsion, or patient mechanics.

The focused tests cover full and reconstructed-half generated extension/compression at rest, midpoint and the exact extended endpoint; old-domain overlap with the prior readout; wrong half factor, missing top BC, inverted force sign, inverted cell, zero logged J, nonfinite stress, altered deck/declaration hashes, wrong frame step/time and inconsistent displacement. The strict upstream parser separately rejects duplicate or missing one-based IDs and altered header time. The next independently reviewed slice must bind actual six native primitives and stream all 61/121 frames, then integrate work and solver residuals before a twelve-row comparator can be considered.
