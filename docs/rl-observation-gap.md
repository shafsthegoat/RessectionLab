# Spatial observations and the remaining transfer gap

The existing native learner is an annotation-assisted procedural policy. It does not infer anatomy from uploaded scans. Its MLP receives action summaries and compact state ([learning.py](../src/resectionlab/learning.py#L238), [feature schema](../src/resectionlab/policy_inputs.py#L14)). This is compatible with the specification's annotation-assisted track; it does not establish the separate end-to-end inference track or unseen-patient generalization ([MASTER_PLAN](../MASTER_PLAN.md#L195)).

Before action selection, target benefit, normal volume and remaining-target fraction use supplied target fractions and exact simulator remaining tissue. Adjacent-target fraction reads endpoint-neighborhood labels ([simulation.py](../src/resectionlab/simulation.py#L378)). Additional native features describe predicted partial contacts after excluding previously charged/removed cells ([native_simulation.py](../src/resectionlab/native_simulation.py#L252)). Expanded-axis proposal endpoints themselves depend on remaining target labels; native previews filter candidates and provide removal/contact footprints ([native_proposals.py](../src/resectionlab/native_proposals.py#L297), [native_axis_simulation.py](../src/resectionlab/native_axis_simulation.py#L265)). Adding a scan encoder to these rows would preserve these privileged shortcuts.

Nominal functional evidence is separated from sampled hidden functional rewards ([native_simulation.py](../src/resectionlab/native_simulation.py#L274)). Availability flags indicate whether nominal arrays were supplied; absent fields become zero internally. Missing-evidence reports retain null functional metrics and null clinical probabilities, but the flags do not force abstention, infer unknown hazards, or calibrate safety ([construction](../src/resectionlab/native_simulation.py#L99), [reporting](../src/resectionlab/simulation.py#L475)).

The native environment does model sequential removal: contained source cells, connected frontier, and shaft clearance through the prior cavity are checked at each microstep. It assumes an intracranial aperture and rigid tissue; it does not simulate scalp/skull opening, deformation or clinical injury ([native_resection.py](../src/resectionlab/native_resection.py#L371)). The retained feature-unit study used zero human pretraining patients and one previously explored structural case; no learned arm exceeded search ([completed result](../artifacts/learning/procedural-native-feature-units-v1/RESULT.md)).

The new [spatial observation contract](../src/resectionlab/spatial_observations.py) separates six image/estimate/state channels, voxel coverage, channel availability, physical affine, complete tool/action geometry, and observed cavity/access/budget. Primary synthetic-scan and inference-only tracks reject supplied annotation channels. Optional estimates must declare scan-only derivation; this declaration alone cannot prove upstream causality. Missing structural scan or observed cavity is an explicit gate. Uncovered values are erased. No future reward, reference mask, predicted removal/contact summary, or caller-supplied action mask enters this adapter. Its mask expresses only STOP and the observed action budget; tool feasibility remains the task's responsibility. Intensities are preserved without normalization. Its fingerprint identifies tensors/provenance; source receipts must additionally join `source_id`.

The smallest next experiment is a bounded paid-opening task with disjoint, prospectively assigned procedural anatomy groups. Hold permitted scans/state fixed and mutate private references: actor tensors, candidate IDs/order/masks and search decisions must remain identical, while evaluator rewards may differ. Verify a costly first opening enables a later action, then compare a spatial policy with search under identical permitted information and missingness profiles. This would establish a synthetic transfer test, not unseen-human or clinical transfer; those require a frozen patient split and audited scan-to-estimate pipeline.
