# Research Planning in the instrument workbench

**Rehearse → Instrument toolbox → Research Planning** compares two source-bound
continuations from the current shared-engine state. It preserves the original
branch, independently checks fresh native replay, and installs two alternatives
for linked 3D/MPR inspection, decision alignment and native save/open. Editing a
checked plan forks a new branch.

This version is explicitly a development continuation comparison. It supports
observation-only local greedy against STOP or the existing pinned seed-17
REINFORCE checkpoint. The latter previously failed its development assessments
and remains unpromoted. It is not the retained native bounded-search planner,
full-start learned access, a TRAIN/SELECT benchmark or clinical validation.

Admission requires the two existing pilot scenes, exact exclusion contracts,
a supplied target, a checked left-CUSA approach and explicit acknowledgement
of missing anatomy. The frozen learner additionally checks its exact weights
and observation/action implementation. Arbitrary cases and missing evidence
produce a visible refusal. Opening anatomy runs no inference or training.

Both methods receive the same nine observation-derived CUSA commands. Geometry
is checked by the shared engine during execution. Rejected attempts stay explicit;
a six-decision limit is truncated rather than claimed as completion. STOP
actually deactivates the left tool. The right tool retains its recorded state.
Cumulative setup burden remains separate from additional target/healthy removal.
Certified reachable-target removal and neurological harm remain unknown, and
unavailable native exposure ledgers are null rather than apparent zero.

Reproduce using the existing local inputs and a new ignored output directory:

```sh
.venv/bin/python scripts/run_research_planning.py --output testcases/research-planning-next
.venv/bin/python scripts/verify_research_planning.py \
  testcases/research-planning-next/comparison.ressectionlab \
  --output testcases/research-planning-next/independent-verification.json
./scripts/launch_poc.sh --case "$PWD/testcases/research-planning-next/comparison.ressectionlab"
```

The CLI reuses existing source data and executes the earlier checked public-action
setup. It binds matching source exclusions in a disposable intact session and
never replaces the source file, injects a cavity or learns new weights. The
separately authored verifier reconstructs observations, scores, actions, rewards,
source-cell removal and native states. This is independent verification code
using the same simulator, not independent physical validation.

Detailed local results, screenshots, preserved learning curves, earlier failed
attempts and reproduction records stay in Git-ignored `testcases/`, as required
by the local working instructions. Consult its README and the local walkthrough.
The first integrated result is negative: greedy encounters a shaft collision and
the learner stops, adding no target removal. UCSF remains DEVELOPMENT; sub-06
remains meningioma. Missing admitted TRAIN inputs and the old PPO checkpoint
must be recovered before the requested full-start diagnostic and frozen
learned/search benchmark can be claimed.

The separately prepared [EDEN intake adapter](eden2020-integration.md) requires
permission evidence and never grants planning or training admission. Restricted
patient files remain untouched.
