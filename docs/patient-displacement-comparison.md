# Conditional patient-displacement comparison

This implements the comparison portion of the [RESECT development protocol](resect-conditional-displacement-poc.md). No patient B destinations, V coordinates, material data or solver runs were used to build these helpers. Analytical controls establish numerical/data contracts only.

`scripts/mechanics_patient_comparison.py:fit_baselines` accepts only the existing typed `ForwardLandmarks`: exactly six measured internal motions, expressed in common RAS+ millimetres after separately verified frame transforms. These are **intraoperative observations**, so this task does not demonstrate prediction from a preoperative scan alone. Hidden simulator material properties, loads, validation outcomes and surgical actions are not baseline inputs.

The three fixed baselines use identical B observations:

- **No shift:** the predicted destination equals its source coordinate.
- **Proper rigid motion:** equal-weight least-squares translation and rotation, with determinant +1. The [Kabsch method](https://journals.iucr.org/paper?cnor=a15629) prevents an improper reflection. Nonunique fits are retained as unavailable; observations are never dropped to rescue a fit. The numerical rank ratio is fixed at `1e-12`; the existing stronger B source-eligibility ratio remains `1e-6`.
- **Inverse-distance-squared displacement:** use all six vectors with normalized weights proportional to `1/r²`. This is a fixed [Shepard-style interpolation baseline](https://doi.org/10.1145/800186.810616), extended componentwise to 3D displacement, rather than a claim to reproduce every variant in that paper. The power two is chosen prospectively as a simple local weighting rule; no bandwidth, neighbour count or exponent is tuned. Exact coordinate coincidence returns the observed vector. Equal distances have equal weights. Duplicate B positions are rejected. Relative-distance arithmetic avoids overflow near an observation. The method reproduces constant displacement but need not reproduce a rigid rotation or affine strain.

`freeze_comparison` writes the complete evaluable baseline field, protocol/source identities and optional complete external FEM field before any V source or destination access. It uses the unchanged `mechanics_landmarks` freeze/reveal contract. The paired-file audit hash remains outside the forward model. The outer experiment release must fix this study and its output directory; these helpers do not independently authorize patient-data access.

For the optional external field, the frozen manifest binds the original geometry/frame record, rest mesh, nodal displacements, numerical evidence, interpolation source and exact top-level function entrypoint. Rest nodes and displacement vectors remain in native MRI RAS metres, with zero-based tet10 connectivity ordered as vertices 0–3 then edges 01, 12, 20, 03, 13, 23. The geometry/frame artifact freezes the native-metre to common-RAS-mm transform: proper rotation times 1000, plus millimetre translation. The sampler applies its inverse to query positions and its linear part alone to displacement vectors; translations never alter vectors. It receives only V row IDs and source common-RAS-mm coordinates after reveal and returns common-RAS-mm displacement vectors. Provisional alignment remains provisional. This module implements no tetrahedral locator, solver or substitute mechanics. Hash-bound external artifacts are provenance, not proof that the mechanics passed its separate numerical gates.

`evaluate_frozen_comparison` verifies all saved artifacts and executing helper identities, durably records the single evaluation attempt, then reveals V. It has no refitting hook. Even a failed read preserves the attempt marker; the same study directory cannot silently restart. The external manifest accepts only its fixed 12 fields, rejecting undeclared later-image paths or alternate interpolation settings. External interpolation must return a typed result bound to the exact query IDs/coordinates. Outside-domain, unsupported-geometry, ambiguous-location, nonconforming-mesh and uncertain-boundary samples remain null with distinct reasons; there is no nearest-node clamping or zero-filled prediction. Reads themselves are size-bounded, independently of potentially stale file metadata.

All three baselines have global mathematical support, including V outside the FEM domain. Reports retain every method's full supported set and excluded counts, plus the identical support shared across all included methods. Pairwise comparisons use each pair's explicit shared IDs. This prevents FEM exclusions from silently changing a baseline's reported denominator. Global baseline support does not establish that tissue was retained or mechanically represented.

Each supported landmark has a Euclidean error in millimetres. Summaries give RMS, median and maximum error; paired records give first-method error minus second-method error, with negative values favouring the first. Six-B fit residuals are labelled conditioning residuals. Zero supported points produce null summaries, not zero error. No pointwise IID confidence intervals, injury probabilities, action-response validation or clinical tolerance are manufactured from this single development case.

The prospective code is covered by analytical translation/rotation/reflection, exact interpolation, degeneracy, coverage, immutable-input and disclosure-order controls. A deliberately stubbed external field exercises the data boundary only. Actual patient fields and held-out errors remain uncomputed.
