# Scan-only diagnostic preprocessing bridge

`resectionlab.scan_preprocess_bridge` is an optional research adapter for the pinned GlioMODA T1c/FLAIR nnU-Net 2.5.2 configuration. It supplies no network and performs no patient inference by itself. The source-only tests use generated images.

`prepare_scan_only_patch` takes exact SHA-bound T1c and FLAIR images on one atlas grid, an exact SHA-bound support-bit image, and the verified plans/dataset JSON. It checks coded-sform frame equality, [T1c, FLAIR] channel order, bit-7 input confinement, nnU-Net runtime and fixed model-metadata hashes. It runs the actual `DefaultPreprocessor` without an annotation and returns a center 128³ tensor plus crop, spacing, physical-frame and source metadata. A missing modality, altered plan, frame mismatch or unsupported input fails closed.

`PreparedDiagnosticPatch.decode_supplied_logits_for_display` accepts finite [3,128,128,128] float logits and a separate binary output-coverage patch. It uses the pinned probability resampler before nnU-Net region decoding, then reverses crop and ZYX→XYZ indexing. Paired present/missing support resampling keeps any output with uncertain interpolation support at `-1` unknown; the input bit-7 domain is an additional limit. The returned typed `DiagnosticDisplayOutput` carries states, conservative output coverage and JSON-safe metadata. Its `planning_eligible` and `evaluation_eligible` values are always false. Coverage in the scan does not mean the network produced logits there; a single patch is not a whole-volume prediction.

For generated validation in the pinned optional runtime: `ITK_GLOBAL_DEFAULT_NUMBER_OF_THREADS=1 .tools/scan-target-runtime/venv/bin/python -B -m unittest -v tests/test_scan_preprocess_bridge.py`. Ordinary test collection skips this module if the optional runtime or pinned JSON files are absent. Present but corrupted metadata fails the hash check; it is never treated as an optional absence.

Before a Case4 DEVELOPMENT diagnostic, a separate supervised runner must verify the trusted Case4 scan/support/registration records, the model checkpoint and runtime, and an exact finite logits/output-coverage receipt. Anatomical registration and mask omissions, pretrained overlap uncertainty and image-derived model accuracy remain unresolved. This adapter gives no route, resection, clinical probability or patient admission.
