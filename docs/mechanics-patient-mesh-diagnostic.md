Static evidence suggests a mechanism to test, not a diagnosis: the executed settings disable curvature sizing and clamp requested size to at least 12 mm. Gmsh classifies surfaces using an angle threshold; requesting parametrizable patches does not impose a surface-distance tolerance. Size fields and their global clamps control requested element sizes. These behaviors are documented in the [Gmsh 4.15.2 manual](https://gmsh.info/doc/texinfo/gmsh.html#Specifying-mesh-element-sizes) and [discrete remeshing tutorial](https://gmsh.info/doc/texinfo/gmsh.html#t13). A future local curvature/feature-aware size field with a compatible minimum size is an established-framework option to consider only after this diagnostic. It would remain a new, separately declared candidate with the same fidelity and resource gates.
