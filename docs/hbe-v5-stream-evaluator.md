# HBE v5 complete-stream numerical reader

`scripts/mechanics_hbe_v5_stream.py` is a read-only, source-only checker for one declared HBE_01_03 axial v5 run. The six required file bindings are the old source FEBio deck, newly adapted deck, native mesh JSON, candidate node record, candidate element record, and candidate solver log. The first three must match the frozen twelve-row source/mesh map and pure deck-adaptation receipt. The last three must each have an exact path and SHA256. Candidate adapted decks and output streams must stay below `outputs/mechanics/`; measured-data paths and symlinks are refused, including when the repository root is supplied as `.`. The lower-half representation reads the separately hash-bound full mesh and reconstruction **wrapper** from v4 ancestry, verifies its mesh bindings and schema, and extracts `wrapper['mapping']` for the existing reconstruction class. Reflected fields are labeled as reconstruction, never a native full solve. File hashes do not prove that candidate output text came from FEBio, so a bound saved-stream result reports its output origin as unverified until a separate supervised execution receipt is accepted.

The existing strict `_iter_data_records` parser reads all 61 or 121 initial and converged states for both node and element streams, checking one-based IDs and exact FEBio nine-significant-digit time headers. The existing `check_solver_records` parser requires residual evidence at every declared nonzero state, final normal termination, and no failure or undeclared cutback. The stream creates one validated local geometry/reconstruction snapshot and one fixed 75-probe map; the reused arrays are marked read-only against accidental writes, and the snapshot is bound to one source/deck/schedule contract. `evaluate_prepared_frame` still checks each pair's time, displacement, reactions, deformation, energy, probes, and logged diagnostics. The public `evaluate_generated_frame` still builds its own geometry for a standalone frame. `energy_work_check` integrates the complete signed force–displacement path on the full coordinate and, for a half mesh, on the native half coordinate. It reports every solver residual, the maximum numerical ratios, and full and native work/energy errors. It retains no raw node/element arrays in its result. The parser bounds are 50,000 nodes or cells and 2 GiB per primitive stream; these are input limits, not execution budgets.

Generated fixtures cover a 61-state full tension run and 121-state reflected-half compression run. They use affine displacement with force computed from the declared energy, and they test missing or mistimed records, duplicate IDs, absent residuals, cutbacks, and inverted force. Separate rest-geometry controls open the existing SHA256-bound N16/N24/N32/N36 mesh and reconstruction manifests and validate the embedded mapping; they do not open native solver output. These are numerical and parser controls only. No v5 extended-endpoint native result has been opened or claimed, and no measured HBE response, held-out torsion, patient data, calibration, or native FEBio execution is part of this slice. A `numerical_passed` value from a future saved native run would describe that run's internal checks; it would not establish measured-force agreement, mesh or time-step convergence, tissue fidelity, or clinical validity.

The remaining dependencies before a twelve-row comparison are independently reviewed source closure, a bounded supervised native-run release, actual extended-endpoint native files with verified fixity, and separately accepted numerical convergence criteria. An independent local generated-only N36 profile measured 4.18/4.19 seconds per uncached frame, mostly repeated mesh construction; a profile-only prepared-model experiment returned exactly equal frame results at 1.109–1.116 seconds after a 2.396-second setup. In a separate generated-only check of **this implementation**, preparation took 3.49 seconds, three prepared N36 rest frames took 0.982/0.938/0.937 seconds, and one uncached frame took 4.37 seconds; their output dictionaries were exactly equal. The process reached 1,123,565,568 bytes peak resident memory while retaining both prepared and uncached models, so it does not establish a lean stream memory ceiling. Twelve generated full/half branch/step fixtures also matched the prior committed frame outputs exactly. A 121-frame runtime, memory peak and actual native-log throughput have **not** been measured for this implementation; the old roughly nine-minute and proposed roughly two-minute figures are extrapolations, not validation or release budgets. HBE specimen axial forces would still not validate patient retraction, incision, cutting, or neurological outcome.
