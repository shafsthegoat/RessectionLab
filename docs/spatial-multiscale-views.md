# Permitted multiscale image preparation

[`spatial_multiscale_views.py`](../src/resectionlab/spatial_multiscale_views.py) is an opt-in preparation module. It does not replace the existing access-centered crop, change candidate proposals, certify clearance, run an estimator or connect to a policy/checkpoint. Coarse grids are never native geometry. No patient data were used for its implementation controls.

The API is `PermittedSourceChannel(data, coverage, source_kind, derivation, derived_from)`, `PermittedVolumeSource(channels, affine_ras_mm, track, source_id)`, then `prepare_multiscale_views(source, local_shape=(64,64,64), coarse_shape=(64,64,64))`. The result has `target_local`, `whole_source` and an immutable `report`. Full-source grids are bounded to 32,000,000 cells; each output axis is at most 64. Arrays have XYZ storage and full RAS+ millimetre affines, including oblique/reflected frames. Cell-overlap averaging also supports an explicitly supplied nonsingular sheared image frame; that does not authorize any native-engine geometry change.

Only the existing six permitted channels are accepted: structural intensity, nominal tissue, nominal target, observed cavity, nominal motor and nominal language. Source cavity is binary observed procedure state. Nominal tissue/target lie in [0,1]; functional values are nonnegative surrogates, never clinical deficit probabilities. Annotation-assisted and scan-derived tracks remain distinct. Source provenance is a declaration to verify upstream, not proof that an estimator avoided hidden labels. No reference target, reward, future cavity, postoperative fields, task state or action inventory has an input slot. No image normalization is performed here.

Every source channel has boolean spatial coverage; uncovered values are zeroed before hashes or target centering. Missing channels have no values/coverage and remain explicitly unavailable. Source intensity and observed cavity are essential. Local preparation additionally requires positive covered nominal target evidence; missing, all-zero or fully uncovered nominal target fails with `TARGET_LOCAL_UNAVAILABLE`.

The native local crop uses the bounding-box midpoint of all positive permitted nominal cells. Start is `floor((bbox_min+bbox_max−(crop_shape−1))/2)`, with lower-index ties, then clamped inside the source. Actual dimensions are `min(requested, source)`; no padding, rescaling or hidden-label crop selection occurs. The affine retains original voxel axes/lengths and translates by the chosen integer start. Oversized or disjoint targets can be clipped, even completely. The report gives retained nominal mass and clipped fraction; it does not silently enlarge the crop or claim all target evidence is visible.

Whole-source coarse cells use separable exact rational overlap lengths, evaluated in float64. Index mapping is `source=(coarse+0.5)*(source_shape/coarse_shape)−0.5`, preserving the entire physical cell extent from −0.5 to shape−0.5. Values are averages over each whole cell, with uncovered values zero; separately averaged coverage is the known-volume fraction. Partial coverage is unknown remainder, not observed zero. Small lesions contribute their fractional mass. Observed cavity consequently becomes fractional occupancy. This output has a distinct `PermittedView` contract and must not be passed silently into legacy `SpatialInputs`, whose cavity/coverage are binary.

Views expose `image_channels`, `coverage_fraction`, `channel_available`, `affine_ras_mm`, immutable channel provenance and fingerprints. Computed source identity uses only permitted arrays/coverage/frame/track/provenance; caller `source_id` stays an audit label outside view payloads/hashes. `PREPROCESSING_VERSION` identifies the algorithm. `preprocessing_hash` includes source-specific preparation and affine, so it is a per-case identity, not a universal checkpoint compatibility key. Future model integration must prospectively bind version, configured grids and semantics; old checkpoints are not automatically compatible.

The 28 [owner controls](../tests/test_spatial_multiscale_views.py) passed, including independent geometric-overlap integration, physical extents, conservation, missingness, clipping and tamper/source-report joins. One constructed sparse 193×211×157 source (6,393,511 cells; three available channels) took 0.205 s to construct and 0.187 s to prepare, with 494,125,056 bytes process peak RSS. Target mass error was 1.42×10⁻¹⁴ mm³ (relative 4.96×10⁻¹⁶); extent error 3.33×10⁻¹⁶ mm. This is a software cost observation, not a patient benchmark or worst-case 32M/six-channel memory bound. Independent review is recorded separately.
