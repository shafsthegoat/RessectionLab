# Opt-in native-history batch integration

**59 owner checks and 14 independent checks passed**, in separate focused runs.
The scalar backend remains the default. No patient, complete-size analytic
history timing, matrix rerun, or learning update was executed for this slice.

The production kernel retains the reviewed standalone prototype's executable
mathematics; a source-AST check permits only its module description and version
constant to differ. The scalar distance oracle is unchanged. Active contacts and
prior-tissue shaft scans can opt into bounded batches; general motion and hard
exclusions continue through scalar checks. No feasibility or occupancy is cached.

Owner parity checks compare exact complete certificates, each active-contact
set, each shaft query, and every remaining-tissue/connected-cavity prefix on
two-cut histories generated by the native engine. Identity, anisotropic-oblique,
and mirrored LPS source frames pass. Rejected histories preserve partial-contact,
containment, short-tip future-removal borrowing, hard-exclusion, and accounting
failures. Default geometry never enters the batch helper.

The independent review adds hand-calculated contact/cavity prefixes, retained
lateral partial tissue, disconnected-frontier rejection, deterministic physical
first witnesses, and cancellation during a pending second cut's contact or shaft
scan. The earlier accepted prefix remains accounted, while the pending cut is
not accepted and no complete certificate is returned.

Owner evidence: `owner-attempt-01/{baseline.json,tests.txt,receipt.json}`.
Independent evidence: `../independent-native-batch-review-v1/`.
All source hashes were unchanged during their respective checks. The owner test
run took 1.34 seconds of pytest time; this is a verification duration, not a
performance benchmark.

The standalone kernel's tiny raw-distance differences and negative fallback
timings remain relevant. Nothing here establishes full-audit speed or universal
bitwise numerical equivalence. A future timed scalar → batch → scalar comparison
requires its own declaration and root release, using one previously certified
analytic history and verifying its recorded source/config/history identity.

Backend selection, batch size, and frozen source belong in experiment metadata.
Scientific certificate fields and the tissue-removal model are unchanged. See
`../../docs/independent-native-batch.md` for scope and limitations.
