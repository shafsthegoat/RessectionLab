# Generated 64³ matched recomputation control

One pinned GlioMODA nnU-Net checkpoint was run once per arm on the same generated `[1,2,64,64,64]` FP32 input. Both arms used the tracked tiled Conv3d adapter, the same lazy final decoder and native full-feature-map InstanceNorm. Neither attached dense module hooks. The second arm alone recomputed the first encoder stage when the decoder requested its skip. Contract SHA-256: `df13db40de28b9782dc7b5e3110538b7b4671aaefec2249d6a57977bbfc9d4b2`. This is a generated-input software experiment, not patient inference or clinical evidence.

Both one-shot arms passed independent preflight and resource guards. The saved logits are byte-identical to each other and to the accepted historical 64³ baseline: NPY SHA-256 `377bb7a1dc0bea971ab3c2890432d20c2230744b479a5e7605bd824b0a81ddb1`, raw SHA-256 `52252550d12d7fc0ddd930c044f58cd6e1bca00606646bbd9780687bce3f2853`. All 786,432 logits match exactly; the predeclared `atol=rtol=0.001` test and exact sequential decoded-label test pass with zero differences. The comparison kept the two full NPY arrays outside this compact package and binds them by hashes in the copied results.

The matched hook-free baseline sampled peak RSS was 759,906,304 bytes; recompute was 723,419,136 bytes, 36,487,168 bytes (34.80 MiB, 4.80%) lower in this one ordered pair. Recompute already used 16.73 MiB less before forward, leaving an 18.06 MiB difference after subtracting each arm's pre-forward marker. Forward times were 0.542 and 0.615 seconds. The 20 Hz sampled peaks and single sequential runs do not establish a dependable memory saving or speedup. Both host traces stayed at normal pressure with flat swap, exact live acquisition identities and clean identity-bound finalization.

The first attempt to invoke the saved comparator used invalid mode `recompute`; its CLI guard refused before loading arrays or writing a comparison. The correct `pair` mode then ran once and passed. A root transcription of the terminal result is included and labeled as a transcription, not a native log. The independent audit records this as a setup negative, not a model failure or additional forward pass.

The package includes the exact contract, 18 source/test snapshots, generated-input receipt, acquisition declarations, both arm release/guard/result/log receipts, both saved comparisons, the transcribed CLI negative and three independent reviews. It excludes logits arrays, weights, imaging data and patient records. Earlier 128³ pressure-stopped failures remain unresolved; this result does not support a full-patch or patient-performance claim.
