# Conservative target-potential bound for conditional model checking

The guarded frozen ranker preserves all four original TRAIN routes but adds 344 terminal geometry checks. This opt-in utility tests whether public target information can eliminate some unnecessary checks without changing the conditional planner's winner. Model weights, first-eight shortlist, world and actual reward remain unchanged.

`public_reward_bound.py` takes explicit public target/domain, observed cavity, affine, tool trajectory and reward coefficients. It conservatively counts positive target cells intersecting an outward-rounded envelope of the full active sweep, including pre-entry and tip caps. Fractional membership counts as one; nonnegative outside-target and motion costs are omitted from the upper bound. It retains full checking for unknown coverage, unsupported inputs and workspace limits. A skipped action is reward-dominated, not certified geometrically safe or impossible. Positive ties retain exact checking and raw ordering.

The utility is canonical and reusable; the conditional policy wrapper remains explicitly experimental. Canonical portable tests pass **17 in 0.29 s**. The combined generated native-policy controls pass **20 in 0.87 s** (owned 1.296 s, 90.44 MB). Independent source review reports no blocking defect. Controls include native full-cell containment as a separate oracle, reflected/rotated anisotropic frames, caps, missing coverage, snapshots, ties, private-reference independence and paid interruption without partial STOP.
