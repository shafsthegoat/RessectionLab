# Native channel-chunk InstanceNorm: generated operator negative

The earlier hand-written in-place normalization is still **rejected**: its large-offset/low-variance generated case differed from native PyTorch by 1.76289 with 43 activation-sign changes. This version calls PyTorch's native `InstanceNorm3d` on complete spatial maps, one or more channels at a time, then copies each result into a fresh Conv3d output. It does not recalculate statistics by hand or normalize spatial slabs.

Six tiny generated tests passed in Torch 2.14.1. Native whole-map and channel-chunk results were byte-identical for random affine batch input, chunks of 1–4 channels, the prior represented `1e6 ± 0.1` counterexample and a near-constant map. A retained alias to the *input* skip remained unchanged. The candidate rejects hooks that could retain the Conv output, custom Conv/Norm forwards, training/autograd, unsupported norm state, float64, strided or channels-last input, and views. Its ownership argument is limited to calling an exact native Conv3d internally, with the generated Conv output private until returned. It is **not attached to the pinned tiled Conv3d network**, whose wrapper and block graph would need separate ownership and alias review.

One prospective small `[1,8,24,24,24]` FP32 CPU allocator profile compared `norm(conv(x))` with channel-1 native normalization. Both produced exactly equal outputs, but **both reached the same PyTorch-tracked peak of 12,835,648 bytes**. Each timeline contains an early large transient before steady-state allocations; it does not identify that allocation's exact operator. These timelines measure PyTorch CPU tensor allocation, not process RSS or all native workspace. They do not prove the method can never save memory at other shapes; they provide no measured peak benefit in the tested Conv→Norm path. The chunk path also created more allocation timeline events (308 versus 44).

The result is a **HOLD** on trained-model attachment and further full128 attempts with this method. No checkpoint, pretrained model, 128³ tensor, patient data or host-pressure probe was read or run. We stop this optimization here rather than selecting another chunk size or relaxing numerical/resource gates after a nonbenefit.
