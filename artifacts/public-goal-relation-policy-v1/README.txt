Public goal-to-tip relation policy: prospective source evidence

This package records source and a fixed future TRAIN experiment. Root has copied
the reviewed nine production/test files into the working tree. Root canonical
tests passed107 in9.07 seconds; the exact log and current nine source pins are in
canonical-test-receipt.json. The fit has not run. Static source GO is recorded
separately under independent-source-review and retains its original pre-test
status as historical evidence. This is not a trained model, performance result
or desktop checkpoint publication.

The motivation is the unchanged architecture's saved full40 TRAIN behavior:
28/40 teacher-state agreement, but only6/24 complete native contacts versus
16/24 for original saved SEARCH. All six moving episodes reached the goal;
ten positive roots chose STOP. On pcf14/23 surface goals the actor used the
deep-goal trajectory, removing3mm3 instead of1mm3 and losing .412/.408 return.
Scores differed with the public goal, so this does not establish goal blindness,
a source bug or representation impossibility. Original failures stay recorded.

The new opt-in architecture appends goal-minus-candidate-tip displacement in
orthogonal crop-axis physical mm divided by the existing10mm reference, plus
distance, to each candidate scorer. STOP receives the legal aspiration/probe
mean/max/log-count summaries of those public relations. Source/goal/crop/frame
context is validated before extraction. No future native score/removal, private
reference, teacher action identifier, hidden property or reward enters features.
The image/ray/current geometry inputs and masks remain. The critic is unchanged.

Every shared initial tensor is exact;704 added actor/STOP weights start at zero.
The existing seed alone is not the comparison control. All40 initial logits and
values must match the saved baseline numerically within1e-6 before any update.
Architecture and checkpoint identities are distinct; defaults and old artifacts
remain unchanged. Physical feature translation/joint-rotation consistency does
not establish invariance of the inherited network. A benefit could use legal
count/mode cues as well as goal geometry; this single arm does not isolate them.

The fixed prospective arm uses the same ordered40 original TRAIN states and
eight STOP labels,32 full-batch updates, unchanged CE/Adam/hyperparameters,
1280 loss plus80 before/after readout forwards. It starts from fresh controlled
initialization, reconstructs24 original tasks/40 teacher steps, runs no new
teacher/search and loads no original checkpoint. One reload verifies only the
new final file. Endpoint selection, tuning, SELECT/MEASUREMENT and patient reads
are excluded. Caps: one attempt,180 seconds,1GiB sampled owned-tree RSS,one
thread,2048 previews. Any failure/partial remains; there is no automatic retry.

Compare the fixed endpoint to the already saved old full40 endpoint at the same
update/state/forward count, reporting704 extra parameters and actual time/RSS.
This is not a matched-total-compute comparison to the original128-forward pilot
or to scratch RL. Report all40 fixed states, root/second/STOP groups and paired
