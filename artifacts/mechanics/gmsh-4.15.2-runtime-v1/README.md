# Private Gmsh 4.15.2 runtime verification

The exact arm64 wheel declared at commit `5554d38a8f9ede8f660467f8a6162121b0c46678` was downloaded once, verified, privately extracted, and subjected to one non-GUI API/version probe. No meshes, tissue curves or patient data were opened. Meshing needs a separate execution release.

`runtime-receipt.json` is the consumer contract. Its SHA256 is `705056d13e78f98fda0ab04884c0c6e3b31ead73f88d01b6dcf3bd99d5417137`. The `module`, `library` and `interpreter` objects contain absolute paths and byte hashes; the interpreter hash applies to `resolved_path`. Consumers should verify this receipt and these files before using the explicit module path, then confirm `gmsh.__file__`, `gmsh.lib._name` and version, and rehash after use. Runtime data remain ignored under `data/optional-runtimes/gmsh-4.15.2`; nothing was installed in the app or a global environment.

The 36,427,761-byte [official PyPI wheel](https://pypi.org/project/gmsh/4.15.2/#files) matches frozen SHA256 `f6649b3e59f49272e7ee8ab282ecb4d1a6e0d627e86cf3e3b1a83fd07417e4f8`. The transfer took 2.693 seconds, with a 60-second limit and no redirects, retries or overwrite. The 450 ZIP entries contain 425 regular files and total 97,904,552 uncompressed bytes, below the 256 MiB bound. Paths, member types, duplicates, encryption, lengths, ZIP CRCs and creator file hashes were checked. The RECORD file is itself pinned by the whole-wheel hash; all other files match its declared hashes.

The initial extraction verifier stopped after writing only `gmsh.py`: this creator wheel's RECORD stores literal hexadecimal SHA256 values, whereas the verifier expected the usual URL-safe base64 encoding. The original verifier and failure receipt remain unchanged. Root explicitly authorized a bounded continuation with strict hex/base64/malformed/mismatch controls; six controls passed. The continuation verified and reused the existing wrapper unchanged, exclusively wrote the remaining files, and never repeated the transfer or version probe.

`linkage.json` records an arm64 Mach-O library, current version 4.15.2, with system-library/framework dependencies. The wrapper is `runtime/gmsh.py` (SHA256 `f4b0935cebde899750293d87a643090e5ea33c9b18d249267f507db68a0e01c3`); the library is `runtime/lib/libgmsh.4.15.dylib` (SHA256 `def0f5c10988a986e5e879b3db9669d8fe016a81e2d994bbaf2b8497c6b8a58a`).

The one supervised probe used isolated Python with site loading disabled, explicit module loading, one thread, `readConfigFiles=False` and `run=False`. It initialized, read version/thread options, and finalized; no GUI or geometry operation was invoked. API and runtime both reported 4.15.2. It completed in 1.419 seconds under the 15-second cap. Child self peak RSS was 66,142,208 bytes; 50 ms process-family sampling observed 43,433,984 bytes, so the sampled figure is not the true peak. All 425 files remained byte-identical afterward. Exact drivers, invocation, log and source bindings are retained here.

The upstream GPL-2.0-or-later text and its specified external-library exception are retained verbatim in `LICENSE-upstream.txt` and the private runtime. This receipt covers a separate local research utility; it does not authorize app bundling or distribution. The package also retains its upstream credits and documentation. Primary project: [Gmsh](https://gmsh.info/).
