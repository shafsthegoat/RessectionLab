Concrete implementation
The two staged existing scripts accept keyword-only ogden_alpha=2. The energy
oracle uses singular values of the deformation gradient F and J=det(F)>0:
  W_dev = (2*mu/alpha^2) * sum_i[(J^(-1/3)*lambda_i)^alpha - 1].
Its unit is Pa; quadrature yields J. This is FEBio's one-term c1=2*mu, m1=alpha
convention. The unchanged volumetric term is K/4*(Jbar^2-1-2*log(Jbar)), where
K/mu=149/3 and Jbar is the reference-volume-weighted mean in each hex element.
The general energy uses SVD/log/expm1, not FEBio eigenvalue or stress code.
Nonrepresentable results refuse rather than clipping. Finite nonzero alpha is
the arithmetic API domain; this is not an admissible tissue-parameter range.

The alpha=2 branch retains the original literal energy arithmetic, XML text and
record keys. Explicit nondefault deck requests change m1 only and add receipt
fields declaring the parameter override and native_execution_released=false.
Geometry, full bonding, load endpoints, solver settings, K:mu and all roles stay
unchanged. The original v5 frame/material admissions are untouched: this source
does not make old releases authorize another exponent or certify its numerics.

Generated verification prepared
The test uses only analytic 3x3 gradients and a one-cell rectangular mesh. It
checks finite-difference energy derivatives against independently derived
eigenbasis Piola stress, rotation invariance, repeated stretches, infinitesimal
shear modulus, analytic homogeneous uniaxial/shear expressions, nonuniform cell
Jbar versus pointwise bulk energy, linearity in mu, bad input/overflow refusal,
and exact alpha=2 old/new energy/XML/metadata equality. Homogeneous formulas are
oracle controls only; they cannot replace bonded-specimen equilibrium solves.
Historical compatibility loads the exact two preserved baseline source files.
Future native checks still need independent work/energy, balance, positive-J
and relevant mesh/load-refinement evidence; old alpha=2 PASS does not cover them.
