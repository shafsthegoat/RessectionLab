# Glioma connectivity and outcome source audit

The CSV is reproduced unchanged from Lars Smolders (2024), *Baseline variables
and T0 and T3 cognitive Z-scores*,
[Figshare version 1](https://doi.org/10.6084/m9.figshare.28001120.v1),
under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The paired structural matrices are described in
[Figshare version 1](https://doi.org/10.6084/m9.figshare.28000559.v1).
See Smolders and colleagues (2025), *Presurgical structural connectivity predicts
postsurgical cognitive impairment in glioma patients*,
[Brain Communications](https://doi.org/10.1093/braincomms/fcaf346).

The source receipt pins the data, article, supplement and inspected code.
Matrices remain locally in the ignored dataset directory. Article/supplement
snapshots are also retained locally rather than duplicated in Git. Their hashes
and retrieval locations remain in `source-receipt.json`. Author analysis code was
inspected only; it is not incorporated into this repository.

Our descriptive audit preserves the released values and discrepancies. No model
was fitted. See [interpretation and limits](../../docs/glioma-connectivity-outcome-audit.md).
