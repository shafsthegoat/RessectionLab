The files in 20Normals_*.tar.Z contain images and segmentations of three
dimensional T1-weighted MRI brain data sets for 20 normal subjects.

Uncompress the files:

	uncompress 20Normals_T1.tar.Z
	uncompress 20Normals_T1_8bit.tar.Z
	uncompress 20Normals_T1_brain.tar.Z
	uncompress 20Normals_T1_seg.tar.Z

Untar the files:

	tar xf 20Normals_T1.tar
	tar xf 20Normals_T1_8bit.tar
	tar xf 20Normals_T1_brain.tar
	tar xf 20Normals_T1_seg.tar

This will produce three sub-directories:

   20Normals_T1/       16-bit MRI data
   20Normals_T1_8bit/  8-bit scaled 3D MRI data files
   20Normals_T1_brain/ 8-bit scaled 3D MRI data files (brain regions only)
   20Normals_T1_seg/   voxel values: other=0 csf=128 gray=192 white=254

The first directory contains a sub-directory for each brain data set
each holding roughly 60 positionally normalized 16-bit ".img" slices.
Each of this files is 256x256.  The second three directories contain data
files (.buchar) and header files (.hdr).  The header files have four
ascii numbers that give the size of the data set:

   cols rows #slices byteswap

Where "cols" is the number of columns of voxels, "rows" is the number
of rows of voxels and the origin of the image is at the top left.  The
third number tells the number of slices.  All images are 256x256 so
each file is 256x256x#slices.  The last number, "byteswap" is always
set to zero.

MRI Image Acquisition

The coronal three-dimensional T1-weighted spoiled gradient echo MRI
scans were performed on two different imaging systems.  Ten FLASH scans
on four males and six females were performed on a 1.5 tesla Siemens
Magnetom MR System (Iselin, NJ) with the following parameters:  TR = 40
msec, TE = 8 msec, flip angle = 50 degrees, field of view = 30 cm,
slice thickness = contiguous 3.1 mm, matrix = 256x256, and averages =
1.  Ten 3D-CAPRY scans on six males and four females were performed on
a 1.5 tesla General Electric Signa MR System (Milwaukee, WI), with the
following parameters: TR = 50 msec, TE = 9 msec, flip angle = 50
degrees, field of view = 24 cm, slice thickness = contiguous 3.0mm,
matrix = 256x256, and averages = 1.

Voxel Intensity Range Reduction

Each file in 20Normals_T1_8bit and 20Normals_T1_brain has been reduced
to 8 bit from 16 bit.  This was done by thresholding intensities above
or below 99.99% of the total number of different intensities (to
eliminate high and low outliers) and then by scaling the remaining
range to 0.255 IFF the range did not already fit into 0..255.  In other
words, if there was not enough contrast in the original data, then it
was not stretched to become 0..255.

Positional normalization

All data sets were positionally normalized by imposing a standard
three-dimensional brain coordinate system on each 3D MR scan using the
midpoints of the decussations of the anterior and posterior commisures
and the midsagittal plane at the level of posterior commisure as points
of reference for rotation and (nondeformation) transformation
[Talairach and Tournoux, 1988; Filipek, Kennedy, Caviness, 1991].  The
repositioned scans are then resliced into normalized 3.0 mm coronal,
1.0 mm axial, and 1.0 mm sagittal scans which are used for subsequent
analyses.

Image Segmentation

Segmentation was performed on the positionally normalized scan by
trained investigators using a semi-automated intensity contour mapping
algorithm [Kennedy, Filipek and Caviness, 1989] and also using signal
intensity histograms.  Once the external border was determined by
intensity contour mapping, grey-white matter borders were demarcated
using signal intensity histograms.  Using this technique, borders are
defined as the midpoint between the peaks of the bimodal histogram for
a given structure and its adjacent tissue.  Other neuroanatomical
structures were segmented similarly [Filipek, et al., 1994].
