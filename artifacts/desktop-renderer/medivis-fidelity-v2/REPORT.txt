Medivis-inspired visual fidelity v2

The existing Electron viewer now has substantially less tissue haze, larger
linked source images, a subtle magenta brain rim, and a separate real CTA case
with published arterial and venous labels. Actual GPU captures and independent
cross-review show a closer visual hierarchy and cutaway composition; they do
not establish Medivis parity or anatomical accuracy. Only GPT-6.1 Sol high
subagents were used. Work stayed in the existing primary checkout.

Visible changes
- Explicit edge-shell context and physical-gradient MRI extinction reduce the
  gray interior veil. Uniform transparency remains selectable; old saves retain
  it unless a new presentation is selected. Float LUTs retain low extinction.
- MRI slices use more of each tile, with physical-scale content/full-image fit,
  visible zoom controls, and synchronized pointer/overlay sampling. Full source
  extent remains accessible. Default zoom is 100%; 125% can crop pane edges.
- CTA context uses its declared packed source membership and configured ivory
  color. High contrast alone no longer forces a voxel to opaque bone when a
  context label exists. Rust/blue artery/vein identities come from publisher
  labels. Opaque context, axial cutaway, orbit and linked CTA slices work.

Acceptance and performance
- Production build passes; 707 desktop tests pass (164 main, 392 renderer,
  151 viewer). Python native/portable save workflows: 43 tests pass.
- Full MRI GPU run: 15 checks; final MRI showcase: 7; final CTA GPU run: 15.
  No renderer errors. Source manifest and all 25 MRI / 7 CTA arrays unchanged.
  Checks include presets, reversible structures/volume, opacity, fragment
  inspection, linked cursor, fit/zoom scale, clipping and native save/reopen.
- Final MRI Segmentation: median 25.62 presented FPS, p95 interval 43.20 ms,
  post-drag refinement 574.5 ms. CTA Vascular: 29.79 FPS, p95 47.77 ms,
  refinement 639.4 ms. Each default refinement measurement has N=1.
- End-of-run Electron working-set plus Python RSS snapshots sum to about
  1.04 GiB MRI / 0.98 GiB CTA. These process metric sums are neither unique
  physical memory nor simultaneous peaks. See original report.json receipts.
- Physical pointer/scale agreement in MRI is within 0.015 mm at 100% and
  0.009 mm at 125%, subject to rounded UI coordinates and source sampling.

For full acceptance, use electron/verify-visual-fidelity.cjs with FIDELITY_CTA=1.
FIDELITY_SHOWCASE_ONLY=1 captures a focused presentation; FIDELITY_MOTION_ONLY=1
records motion after separately completed acceptance. FIDELITY_FLUID_MOTION=1
records delivered viewport frames. Mutating checks operate on disposable clones.
To recover a fresh CTA package, copy source-qc/producers/ into the original
outputs/poc-angio-fidelity-v2 location, run recover_selected.py then package_native.py
with the repository Python environment. The packager refuses an existing native
collection. Hashes of original recovered source bytes are the recovery identity;
generated manifest timestamps may differ. correct_semantic_kinds.py is retained
as the historical metadata-only migration receipt, not needed for a fresh package.
