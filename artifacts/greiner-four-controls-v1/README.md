# Evidence layout and reproduction

This archive contains compact review evidence and source snapshots. It is not a new execution release. All native calls are already spent; it authorizes no retry, coarse rerun, altered mechanics, measurement parsing, fitting, or model run.

`artifact-index.json` binds every other file in this artifact directory by exact byte count and SHA-256. `snapshot-map.json` maps each copied snapshot to its original path and exact original hash. Files ending in `.compact.json` preserve the entire original JSON value without projection or dropped fields. Their original bytes reconstruct exactly with Python's `json.dumps(value, sort_keys=True, indent=2, allow_nan=False)` followed by one newline. The compact file hash and reconstructed original hash are separate and both retained. `verify_package.py` checks these identities without executing a solver or changing source files.

The compact receipts preserve all complete pre/post audit maps, original runtime/command/thread records, warning lines, output bindings and checker values. `results/` contains the three new full checker results. `saved-coarse-supplement.compact.json` contains the authenticated original coarse replay, including all 53 state rows. `original-negative/` preserves the unchanged original failed receipt, summary, release and independent audit. Its source counterparts also remain in the earlier `artifacts/greiner-first-control-inventory-negative-v1` archive.

`source-map.json` identifies the ten executing sources: the three ignored executing modules are copied byte-for-byte under `source/`; the seven tracked helpers are reproducible from their exact paths in historical commit `1ede7500a1771323b3cf817cdb14906e8fee9bf5`. Additional snapshots preserve the preparation generator, candidate tests, independent tests and postrun audit. `decks/` contains the exact three executed deck inputs. Restoring snapshot files for inspection does not authorize execution.

`retained-output-inventory.json` binds all 35 original and continuation output files totaling 1,966,363 bytes. Native log streams and plot payloads are intentionally retained outside this compact archive at the original ignored attempt paths. Full saved-output replay requires those files and the hash-bound runtime/reference closure from the preparation; the archive alone is not a replacement for them. `input-audit.json` preserves the exact 198-entry final audit also found in every new case's pre/post phase. Historical source bindings and saved guards are the execution evidence; later unrelated checkout commits do not invalidate them.

`independent-audit.compact.json` contains exact finalized byte accounting, resource checks, state metrics, continuum errors and refinement ratios. The controller summary's pre-final-write byte snapshot is 42,022 bytes smaller than the independently counted finalized tree; no resource cap was exceeded. `warning-source.json` binds the accepted-runtime source branch that emits the retained small-residual warnings.
