# Prospective generated CPU native versus depth-tiled network control

This is a fresh, ignored experiment. It does not replace Gate A v3's failed CPU receipt and does not admit its 32×64×64 input, the 128³ planned patch, MPS, or a patient scan. The first arm is the pinned GlioMODA nnU-Net with native CPU `Conv3d`; the second, conditional arm keeps the same safely loaded FP32 weights and substitutes **only unique `Conv3d.forward` methods** with the reviewed output-depth tiling operator (tile=4). InstanceNorm, ConvTranspose3d and all other operations run on assembled full feature maps. The wrapper rejects unsupported padding and proves parameter, state-dict storage and module identities unchanged before and after attachment.

The new deterministic generated input is `[1,2,32,32,64]` with integer formula `((flat_index*37 mod 101)-50)/50`, saved and SHA-pinned. Five stride-2 reductions leave a 1×1×2 bottleneck, with two spatial elements for InstanceNorm. Each arm uses the exact reviewed Gate A v3 30-second preflight, 20 Hz direct macOS pressure/available/swap and descendant-aware RSS guard, 0.5-second background inventory, 3 GiB RSS and 120-second wall caps. The exact live ReMIND downloader allowlist remains pinned and running downloads are never signaled. The tiled arm cannot launch without an accepted native result bound to the same contract/input/checkpoint. Both arms are one-shot; deferred preflights do not start a child.

The worker retains the earlier scoped `torch.load(weights_only=True)` four-entry NumPy safe-global allowlist, strict key/shape/value copy and alias checks, model file hashes, and no nnU-Net folder initializer. The worker, supervisor, sampler, inventory, comparator and tiling sources are hash-pinned in `control-contract.json`; both arm receipts record the contract SHA. The comparator rejects any changed contract/checkpoint/arm provenance, then applies the unchanged `rtol=atol=1e-3` FP32 logit comparison and exact sequential region-decoded label agreement with threshold-margin diagnostics.

Preparation evidence: `preflight_static.py` verified 22 unchanged V3 resource policy keys, source/input hashes and pinned plan geometry. `wrapper-generated-tests.json` passed on a tiny generated Conv3d+InstanceNorm block, preserving every recorded identity; its max output difference was 7.15×10⁻⁷, so exact bitwise equality is **not** assumed. It rejected reflect/same padding and a second wrapper attachment. `comparator-generated-tests-v2.json` passed synthetic receipt/region-order checks and rejected wrong contract/checkpoint hashes. Invoking the tiled supervisor before a native receipt failed before any child as intended. `readiness.json` lists exact source/input hashes. No checkpoint load, trained network forward or patient data was used during this preparation.

After independent exact-hash review and a serialized quiet-host window, root may launch the native arm from the repository root with `python3 build/limited-input-guard-design/gliomoda-depth-network-control-v1/supervise_control.py native`. The tiled arm is held until the native resource receipt and logits have independent review; if admitted, its command is the same with `tiled`. The comparison is a separate read-only step using the isolated pinned Python runtime. Any guard stop or numerical disagreement remains a recorded negative result, without cap or acceptance-threshold changes.
