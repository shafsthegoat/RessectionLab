The explicit supplied_goal_region_may_exceed_estimated_support opt-in preserves
the original observed-support and supplied-target arrays. It neither unions the
target into support nor clips the target to support. Native configuration still
receives the original support and zero engine target labels. Native removal
still filters touched cells through that support and current remaining_mask;
commit still requires every removed cell to have been remaining tissue. Reward
still sums target membership only at the committed removed indices. This change
does not let an unsupported positive target cell become removed or earn reward.

The nominal/cavity proposer continues to start from engine.remaining_mask before
examining nominal target membership. Thus proximal/distal nominal endpoints are
remaining original-support cells. Unsupported-only target columns emit no nominal
ray; exposed-support opening proposals remain possible and carry their ordinary
costs. No proposal generation or physical geometry equations are changed.

The new conditional metrics retain full and unsupported positive counts and
membership volumes. Progress is supported removed nominal membership divided by
the entire unchanged supplied region, including unsupported positives. The full
sum is strictly positive under opt-in admission, so the denominator is defined.
Existing independent episode accounting likewise uses the full reference target
sum. The actual public patient factory must retain its existing nominal/reference
equality condition; the generic NativeSpatialCase still separately represents
nominal and reference fields for other experiments.

Default compatibility is preserved at source level: target_semantics is appended
after all prior dataclass init fields; the default still refuses nominal positives
outside support. The new source-hash/provenance key is included only for the
nondefault mode, and default metrics gain no new supplied-region object. Existing
source/reference/decision/proposal identities therefore retain their original
recipes under default construction. Explicit opt-in changes identity even when
the target happens to fit support. The internal frozen-object identity now also
guards the mode and extent record. No historical identity runtime was rerun here.

Opt-in requires annotation_assisted mode, an explicit nonempty nominal target and
supplied_annotation target provenance. Direct proposer use requires the same
semantics value in its supplied annotation provenance. Unknown mode values and
derived/synthetic target substitutions are refused by the new branch. No role,
QC, actual source linkage, anatomical coverage or model admission is granted.

Interpretation remains PARTIAL_TARGET_PROGRESS. The result does not establish
that the original support is anatomically complete, that unsupported target cells
are safely accessible, or that a full clinical resection occurred. The added
outside-goal wording correctly distinguishes outside the supplied task region
from normal-anatomy truth. Existing generic normal_removed_mm3 field names are
retained for compatibility; their conditional task interpretation must remain
visible in result summaries. Private ventricular labels are not introduced into
the actor, support, objective or proposal machinery by this patch.
