# Browser preview captures

These are historical screenshots of the read-only, actual UCSF source-data
preview. The preview cannot search, train, save or stand in for native app tests.

- `initial-preview.jpg` preserves the early display investigation.
- `route-workspace-camera-fixed.jpg` follows the source-frame camera correction.
- `surface-before-normals.jpg` was captured after the host browser panel narrowed
  to 319 pixels and clipped the anatomy. It is not usable as a surface-quality
  baseline and does not represent the native app's supported minimum window.

Use the matched full-width native `source-baseline.jpg` and
`source-normals-after.jpg` in `../electron-refinement-v2/` for the display-normal
comparison. Native training and replay receipts are recorded there separately.
