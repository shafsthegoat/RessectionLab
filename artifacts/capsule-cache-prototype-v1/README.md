# Synthetic exact capsule-cover cache prototype

`synthetic-probe.json` is the first bounded synthetic receipt, generated by
`scripts/probe_native_capsule_cache.py --repetitions 5`. No patient data,
gradients, final worlds or stress worlds were used.

All fifteen reference/cached/reversal strokes produced the same complete
preview, history, masks and state ancestry. Reference and cached histories each
passed the independent native checker. A hard barrier still rejected the
complete tool before any cached tissue-cover query, with zero removal. The
original query symbol was restored after every injected scope.

The cold cache had 46 misses; four repeated strokes had 184 hits and no new
misses. It retained 105,720 bytes of array payload in 46 entries, below the
32 MiB and 16,384-entry caps. One cold stroke took 25.68 ms, warm strokes
12.44–12.49 ms and reference strokes 23.28–30.54 ms. These are local synthetic
observations without an isolated timing window, not a public-case speedup claim.
Peak RSS is cumulative for the whole process; array payload excludes keys and
bookkeeping. Exact source hashes and individual phases are in the receipt.

The initial focused tests passed 16 cases in 0.97 seconds, covering cold/warm,
zero/oversize/eviction, clone/reset, exact physical keys, oblique/mirrored grids,
tangency, source mutation, scoped restoration and the prior-cavity short-tip
counterexample. Subsequent review found two guard-order failures caused by
input conversion mutating source/scene before a warm hit, and two failures when
direct geometry helpers changed without a version change. The initial sources
and failing outputs are retained here. The repair moves authoritative checks
after conversion and binds direct geometry callable references, including scene
coordinate methods. It does not expand the threat boundary to arbitrary Python
or NumPy process mutation.

The repaired focused suite passed 78 tests in 1.93 seconds. The separate
independent reviewer receipt records its own cases and exact source hash.
`synthetic-probe-repaired.json` reruns the fifteen strokes and both independent
audits with the final helper and complete directly imported source-guard file
identity. The same 46 misses, 184 hits and 105,720 payload bytes were observed;
all scientific results remained exactly equal, and the barrier still rejected.
The earlier probe remains historical and is not silently upgraded to repaired
code. Production engine and adapter files remain unchanged. Public timing
requires a separately reviewed prospective declaration and execution release.
