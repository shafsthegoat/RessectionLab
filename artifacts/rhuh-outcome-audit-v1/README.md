# RHUH clinical source and descriptive audit

The CSV is reproduced unchanged from TCIA's public RHUH-GBM release under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Attribution: Cepeda, S., García-García, S., Arrese, I., Herrero, F., Escudero, T.,
Zamora, T., and Sarabia, R. (2023), *The Río Hortega University Hospital
Glioblastoma dataset: a comprehensive collection of preoperative, early
postoperative and recurrence MRI scans (RHUH-GBM)*. The Cancer Imaging Archive,
[DOI 10.7937/4545-c905](https://doi.org/10.7937/4545-c905).

`acquisition.json` records exact source URLs and hashes. `artifact-index.json`
also records reference page snapshots retained locally, outside Git; it is an
acquisition inventory, not a promise that every reference snapshot is vendored.
The independent descriptive audit does not alter source values. No images or
controlled DICOM files are included. See [interpretation and limits](../../docs/rhuh-outcome-audit.md).
