# Frozen proposal scorer on a new TRAIN anatomy

The public factory and source validator now support an explicit, bound TRAIN
development-transfer record. The person must be outside the fitted four-person
cohort; source/manifest/QC/model hashes, original role, full supplied target,
partial source domains, post-exposure assumptions and zero-update scope remain
checked. Default TRAIN and SELECT admissions are unchanged. This is a reusable
source option; the separate experiment entry fixes the next person to TRAIN050.

The direct loader authenticates the previously fitted balanced ridge parameters
without a neural checkpoint API. Its comparison retains top8, the same proposal
catalogue and full-tool geometry, and a lean exhaustive control. Both plans are
sealed before fresh uncached authoritative replay. Model loading, construction,
selection, checking and replay costs are recorded separately. A negative result
or accepted STOP is not a quality win; capped work stays incomplete.

Eighteen generated runner/loader controls pass in 3.29 s, including a tiny actual
two-arm native worker, both sealed plans and independently accepted replays.
These use invented parameters and anatomy, with actual patient/model access
denied. After integration, 88 canonical source/factory/domain controls and nine
subtests pass in 1.92 s. Three historical-source comparisons skip because their
explicit baseline locations are absent; new transfer controls do not skip.
The portable new test runs from the normal tests directory without ignored
experiment sources or acquired payloads.

The first draft had a static worker import-name mismatch, caught and fixed
before execution. Independent review confirms all 54 original admission guard
calls remain intact. No guard was relaxed to make the generated run pass.
