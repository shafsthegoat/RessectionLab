## Established API and scientific boundary

Apple's [`fcntl(2)` manual](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man2/fcntl.2.html) says a nonzero `F_NOCACHE` argument turns data caching off for a file descriptor, and zero turns it on. Apple's [file-system performance guidance](https://developer.apple.com/library/archive/documentation/Performance/Conceptual/FileSystem/Articles/FilePerformance.html) recommends disabling caching for large one-pass reads that will not be needed soon, warns to measure before and after, and recommends 4K-aligned buffers for uncached reads. That guidance is explicitly marked retired, so this remains an empirical candidate on the installed macOS. The [Apple XNU header](https://github.com/apple-oss-distributions/xnu/blob/main/bsd/sys/fcntl.h) defines `F_NOCACHE=48` for the current descriptor, distinct from `F_GLOBAL_NOCACHE=55`. We use only `fcntl(fd, F_NOCACHE, 1)` on an existing **read-only** handle. We do not use global cache flags, `F_NODIRECT`, cache purge, or altered files. Neither the manual nor this protocol guarantees eviction of pages already cached or guaranteed host-memory recovery.

## Exact intervention

The baseline arm calls the frozen `scripts.mechanics_hbe_v5_remaining_one_shot.validate_release` unchanged. The hinted arm calls the same function and wraps only its *outer predecessor-chain* interval. For an exact prior-attempt directory file that is regular, at least **16 MiB**, and within the frozen `file_hash` size cap, `hash_hint.NoCachePath` opens the same path in `rb` mode and applies `F_NOCACHE` on that handle **before the first read**. It then delegates to the original `io.file_hash` body: same `lstat` regular-file/size check, 1 MiB SHA-256 read loop, second `lstat` identity check, and returned digest. A failed `fcntl` is terminal before reading; the stream is closed. Files outside these exact directories, small files, symlinks and oversize files follow the untouched original guard. The wrapper is restored immediately after predecessor validation. It does not touch source-map/deck material, runtime libraries, measured files, controller state, solver settings, or the current HBE source closure.
