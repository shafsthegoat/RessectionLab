# Complete-route obstruction candidates

The opt-in planner now evaluates the original base candidates plus up to 32
obstruction-directed tool movements per state. Previously the shared 120-candidate
cap omitted movements centered on measured co-blockers. Each page verifies at
most eight additional movements from a clean copy of the base certificates;
all pages compete in one search layer before the existing retention rule advances.
Successors regenerate candidates from their own committed cavity.

Native tool geometry, collision checks, transitions, reward and default planner
behavior are unchanged. This is bounded candidate discovery, not exhaustive
coverage of every route. The new task requires explicit page-aware search and
refuses to present a partial action inventory as a complete policy observation.
Authoritative replay regenerates and certifies each selected action. Incomplete
or capped searches remain ineligible for the planned comparison's accepted result.

A generated native control now executes two negative-return preparations followed
by useful target removal and passes fresh replay and independent geometry/episode
evaluation. The same generated case's original candidate family selects STOP.
This establishes software capability only; acquired-anatomy success is unmeasured.

Canonical integration passes 128 tests in 5.02 s (5.468 s parent), including
certificate lifetimes, all-page ranking, cancellation, private-reference
invariance and exact default parity against pinned pre-change sources. Ten older
opening-search comparisons skip because their separate historical source is not
provided. The earlier staged suite passed 67 controls. The subsequent test-only
change makes historical loading portable and adds independent episode acceptance;
the four independently reviewed production hashes are unchanged.

The next matched acquired comparison holds horizon, beam width, retention,
world/reward and resource caps fixed, varying this explicit candidate expansion.
No model fitting, dataset addition, new patient evaluation or physics claim is
introduced here. Patient splits and existing working desktop edits are preserved.

Production is in `native_proposals.py`, `native_spatial_task.py`,
`observed_search.py` and `paged_obstruction.py`; portable controls are in
`tests/test_paged_obstruction.py`. Exact pre-change modules for the optional
historical parity control can be read from Git commit `19f273b` and supplied
with `PAGED_ROUTE_BASELINE_DIR`. Raw data and generated experiments remain local.
