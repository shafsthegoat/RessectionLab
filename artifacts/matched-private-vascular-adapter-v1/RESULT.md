# Matched methods share one private vascular evaluation boundary

`src/resectionlab/matched_private_vascular.py` adapts the existing complete SEARCH/IL/RL/HYBRID strategy records. All four terminal method slots and complete plans are saved, then all nominal replays and geometry checks finish before any private reference loader. The adapter retains original planning/training cost records, failed and abstained slots, and one fixed evaluation denominator. It adds no policy calls or training.

The same evaluator reference is bound across methods, apart from each strategy's own seal hash. Independent review found that a first callback could originally redirect a later method through mutable mappings. The repaired adapter snapshots mappings and immutable binding/world fingerprints before loading, rechecks them before each method and at batch completion, and preserves failures. It also rejects coherent in-place binding mutations with recomputed fingerprints. The old single-method scoring body is reused through a narrow private helper extraction.

Fifty-two candidate controls passed, including three independent mutation regressions and thirty original evaluator controls. Root's integrated 88-test strategy/evaluator set passes in 15.39 seconds. Root initially removed a sys import still used by one test; that 87-pass/1-test-error run and the corrected run are both preserved. The independent audit's initial outer-guard failure is also retained with the explanation that three standard-library zip lookups, rather than patient/model access, triggered it.

This is generated-only interface validation. Test methods use scripted actions and do not demonstrate learned performance. Existing seals labeled GENERATED_T1 are rejected rather than relabeled. Patient identity/roles, derived-model lineage, real registration and full-size resource admission are still required. The adapter provides cooperative per-phase timing, not an overall hard supervisor or hostile-code sandbox.
