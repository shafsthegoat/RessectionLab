Interpretation and recommendation
This is a demonstrated limitation of the frozen 13-column action family under
the current native whole-cell removal semantics. Each present rejected ray has
at least one blocker that cannot be removed by any tested depth on those columns
using either generic tool. More learning cannot make those geometrically absent
cell-removal actions available. The diagnostic does not establish that physical
tissue is unreachable, that the entire task lacks a useful route, or that every
alternative earlier prefix would yield the same outcome. It diagnoses one saved
frontier and the global cell-capacity restriction of its frozen geometry family.

A minimal proposal-family contrast is justified: add a bounded, deterministic
obstruction-centered translated source-normal opening family using only these
authenticated first-hit cells. Keep the same prefix state, native cell semantics,
shaft-before-cut rule, tools, source domains, access/world, and reward. Ask first
whether a new candidate passes native checks and actually removes an excluded
blocker, then whether re-preview unlocks an original blocked ray. Later target
progress is a separate outcome. Do not relax tip/shaft radii or removal physics,
expand into a broad axis search, or treat optimistic capacity as permission to
cut. This is an implementation recommendation, not authorization for another run;
root controls the timing after the frozen050 comparison.
