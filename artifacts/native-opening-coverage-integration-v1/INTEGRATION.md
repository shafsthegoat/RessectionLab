# Public modeled evacuation progress reaches the planner

The improved partial-volume representation was absent from `NativeSpatialTask`.
An optional generated-only path now supplies the terminal-closure model and
post-commit cumulative modeled evacuation progress to both comparison arms.
Admission requires typed declarations, full public crop, a fixed proposal
lattice and mass derived exactly from the public nominal scan threshold.

The record binds source, model, committed state, action and step. It contains no
reference target, future observation or hidden material parameter. This is
evacuation estimated from permitted anatomy and executed actions, not observed
biological removal. Partial coverage remains occupied for shaft clearance.

`return_plus_certified_evacuation_v1` reserves one beam lane for this progress
and keeps one ordinary-return lane. Final reward, STOP, geometry and candidate
budget stay fixed. Verification time/count are reported; no extra preview or
observation is requested. Independent history evaluation receives the explicit
union/volume declarations. Old defaults and retention outputs remain exact.

Root's bounded batch passes **144 tests in 6.04 seconds**. All new controls run:
required committed-source parity, private-reference permutation, forged
progress, clone/reset/STOP, native replay and no extra query. The 26 skips are
older optional historical-source comparisons in the existing opening-lane
suites. Independent source review found a foreign-case authentication gap;
a source/config/contract check and refusal control fix it before this batch.
Tested hashes and command are in `root-controls-01.json`.
